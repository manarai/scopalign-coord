## Purpose

T01c was inconclusive and the exploratory T01y showed that a single
per-dataset scale does not reconcile the v2 and v3 operator spectra. v3
cells carry about 2.1× v2's UMIs (median 7017 vs 3366 per QC cell), and the
gap differs by cell type (monocytes ≈ 3.0×, T cells ≈ 1.9×). This task
removes the depth difference by binomially thinning v3's counts so that each
v3 cell's depth matches v2's depth distribution within its cell type, then
reruns T00c's gene filter and FA and T01c's operator test **unchanged**.

- If the axiom survives at matched depth, the v2/v3 difference in T01c is a
  depth effect; the planner then brings Tom a proposal to add depth
  matching to the design before T02.
- If it fails, chemistry reshapes the wells even at equal depth; the
  project pauses for redesign.

T01c's outcome stays in FINDINGS as it was.

## Scope

### In scope
- Inputs: `data/pbmc_v2_v3/pbmc_v2.h5ad`, `pbmc_v3.h5ad`; QC cells only
  (`obs['qc_pass'] == True`; 992 v2, 1113 v3). QC and `obs['cell_type']`
  stay as staged by T00 (computed on the original counts); thinning does
  not re-run QC or relabel cells.
- **Depth target per v3 cell (quantile matching within cell type).**
  Depth = total UMI count of the cell over all genes. For each cell type
  present in both datasets: rank the type's v3 cells by depth (ties broken
  by barcode order), give the cell at rank `r` of `n3` the quantile
  `q = (r − 0.5) / n3`, and set its target to the v2 depth quantile `q` of
  the same type (`numpy.quantile(..., method="linear")`). For v3 cells of a
  type absent from v2, use the same rule against all v2 QC cells.
- **Thinning:** `p_c = min(1, target_c / depth_c)`; every count `x` of cell
  `c` becomes `Binomial(x, p_c)`, drawn with
  `numpy.random.default_rng(20261014)`, cells in file order, genes in
  column order (CSR order of nonzeros). Cells with `p_c = 1` are unchanged.
  Write `data/pbmc_v2_v3/pbmc_v3_thin.h5ad` (same `obs`, `var`; thinned
  integer `X`). v2 is not changed.
- **Genes, normalisation, FA:** exactly as `tasks/T00c.md`, with
  `pbmc_v3_thin` in place of `pbmc_v3`: detection in ≥ 3 QC cells of each
  dataset; top 2000 HVGs (`seurat_v3`, `batch_key=None`) on the
  concatenated raw counts; genes sorted alphabetically;
  `normalize_total(1e4)` + `log1p`; `FactorAnalysis(30,
  random_state=20261014, max_iter=2000)` fitted separately on v2 and on
  v3-thin. Tangent rank as in T00c (k = 40 other cells, floor 0.05).
  No PCA or LDVAE.
- **Operator test:** exactly as `tasks/T01c.md` (drift config, Jacobians,
  symmetry check, `classify_basin_latent` with dataset-specific tol,
  tested-type rule, `m_t`, all draws on one `default_rng(20261014)` in the
  same order, all W2/W1/TV definitions, ratio convention), with the new FA
  latents of v2 and v3-thin. The v3 side of every T01c statistic is v3-thin.

### Out of scope
- Thinning v2, upsampling, or any depth model other than the rule above.
- Re-running QC, relabelling, or changing the gene-filter, HVG, FA, drift,
  draw or decision-rule settings.
- PCA, LDVAE, any other dataset, any alignment.
- Reusing T00c's or T01c's latents or operators (the gene list and v3
  counts change, so everything downstream is refit).

### Decision rule
Applied top to bottom; the first matching line decides.
0. **Validity** (not outcomes): `depth_match_max_rel > 0.05`, or
   `n_hvg_zero_v2 > 0` or `n_hvg_zero_v3 > 0` → **REVISE**. FA not
   admissible by T00c's rule (median rank ≥ 10 in both, gap ≤ 5, ceiling
   fraction ≤ 0.20) → **inconclusive** (no admissible layer at matched
   depth; stop).
1–6. T01c's decision rule, unchanged: symmetry > 1e-4 → REVISE;
   `n_cell_types_tested < 3` → inconclusive; any `*_sep_*` < 2 →
   inconclusive; `spectral_ratio > 3.0` or `basin_ratio > 3.0` → **axiom
   fails at matched depth**; `spectral_ratio ≤ 1.5` and `basin_ratio ≤ 1.5`
   and `class_tv_ratio ≤ 1.5` → **axiom survives at matched depth**;
   otherwise inconclusive.

### What would change my mind
`spectral_ratio > 3.0` at matched depth, with operators that separate cell
types, means the v2/v3 difference is not a depth effect: chemistry itself
reshapes the wells for this pair.
