## Amendment log

- 2026-10-14 (before any executor run, before any data was staged): velocity
  source fixed (RNA velocity, scVelo stochastic) because scJDO2's estimator
  fits Jacobians from positions and velocities; `k` raised 30 → 50 so the
  kNN ball exceeds the 30 latent dimensions; W2 cost convention, split-half
  null and stability tolerance made exact; a guard added so that
  all-saddle classes cannot count as agreement.

## Purpose

scOpAlign's axiom is that batch effects change where cells are, not how they
move. The cheapest test is a dataset where the *same biological sample* was
profiled under two chemistries, so any difference is technical by
construction. If per-cell operator spectra and stability classes already
agree across the two chemistries **before any alignment**, the axiom
survives and T02–T05 proceed. If they do not, the axiom fails and the
project stops at this task.

## Scope

### In scope
- Dataset: `data/pbmc_v2_v3/pbmc_v2.h5ad` and `pbmc_v3.h5ad` as staged by T00.
  No other dataset.
- Cells: `obs['qc_pass'] == True`. No further filtering.
- Genes: intersection of `var_names` present in both files, then top 2000
  HVGs computed on the **concatenated raw counts** with
  `sc.pp.highly_variable_genes(flavor='seurat_v3', n_top_genes=2000, batch_key=None)`.
  The same gene list is used for both datasets, in the same order.
- Normalisation (each dataset separately, after subsetting to the HVGs):
  `X`: `sc.pp.normalize_total(target_sum=1e4)` then `sc.pp.log1p`.
  `layers['spliced']`, `layers['unspliced']`: each scaled per cell to a total
  of 1e4 counts over the 2000 HVGs (cells with a zero total in a layer keep
  zeros). No log on the layers.
- Positional layer: `sklearn.decomposition.PCA(n_components=30, svd_solver='full',
  random_state=20261014)` fitted **separately** on each dataset's dense `X`.
  Store as `obsm['X_pca']`. Do not share loadings.
- Velocity (scVelo 0.3.3), per dataset:
  `scv.pp.moments(adata, n_neighbors=30, use_rep='X_pca')`, then
  `scv.tl.velocity(adata, mode='stochastic')`. Gene velocities `V` =
  `layers['velocity']` with NaN set to 0.
- Velocity in PCA space (chain rule for the log1p transform):
  `v_pca = (V / (1 + layers['Ms'])) @ pca.components_.T`, shape (n_cells, 30).
- Operators: `scjdo2.field.JacobianField(k=50, seed=20261014).fit(X_pca, v_pca)`,
  other `FieldConfig` values at their defaults (ridge 1e-4, no radius).
  Cells whose Jacobian is NaN are dropped from every downstream number; their
  count is reported.
- Eigenvalues: `numpy.linalg.eigvals` of each 30×30 Jacobian.
- Matching across datasets: by `obs['cell_type']` only, never by position.

### Out of scope
- Any alignment, Procrustes, CCA, Harmony, scVI, or correction of any kind.
- Any nonlinear embedding (UMAP, t-SNE) anywhere, including figures.
- scVelo dynamical mode, `scv.pp.filter_and_normalize`, velocity graphs or
  velocity embeddings.
- Varying `k`, `n_components`, HVG count, normalisation, or seeds.
- Gene-level loadings or eigenvector comparison (that is T02).
- Any other dataset, including `pbmc_10k_v3`.

## Pre-registration

All Wasserstein distances use uniform weights, a cost matrix
`M = ot.dist(P, Q, metric='sqeuclidean')` on eigenvalues as (Re, Im) pairs,
`ot.emd2(a, b, M, numItermax=10_000_000)`, and report
**W2 = sqrt(emd2)**. A "draw" uses `numpy.random.default_rng(20261014)`,
one generator for the whole stage, consumed in the order written here.

### Gated numbers
| name | definition | computed by |
|------|-----------|-------------|
| `n_cells_v2` | QC cells in v2 | `python reports/T01/scripts/t01_run.py --stage counts` |
| `n_cells_v3` | QC cells in v3 | same |
| `n_ops_valid_v2` | v2 cells with a finite Jacobian | `python reports/T01/scripts/t01_run.py --stage operators` |
| `n_ops_valid_v3` | v3 cells with a finite Jacobian | same |
| `spectral_w2_pooled` | median over 200 draws of W2 between the eigenvalue clouds of 100 cells drawn without replacement from v2 and 100 from v3 (each cloud 100 × 30 points) | `python reports/T01/scripts/t01_run.py --stage spectral` |
| `spectral_w2_null` | median over 200 within-chemistry draws (100 from v2, then 100 from v3): draw 200 cells without replacement from one dataset, split into two halves of 100, W2 between their clouds | same |
| `spectral_ratio` | `spectral_w2_pooled / spectral_w2_null` | same |
| `spectral_ratio_scaled` | the same ratio after dividing every eigenvalue of a dataset by that dataset's median abs eigenvalue (secondary; not in the decision rule) | same |
| `frac_saddle_v2` | fraction of valid v2 cells classed saddle | `python reports/T01/scripts/t01_run.py --stage stability` |
| `frac_saddle_v3` | same for v3 | same |
| `stability_agreement` | fraction of cell types with ≥ 50 valid cells in both datasets whose majority class is the same in v2 and v3 | same |
| `n_cell_types_tested` | number of cell types meeting the ≥ 50 rule | same |

Stability class of a cell, with `tol = 1e-6 × max_i |λ_i|`:
stable if every `Re λ_i < −tol`; unstable if every `Re λ_i > +tol`;
otherwise saddle. A cell type's majority class is its most frequent class;
a tie counts as disagreement.

### Decision rule
- `n_cell_types_tested < 3` → **inconclusive** (too few types to test).
- `frac_saddle_v2 ≥ 0.95` **and** `frac_saddle_v3 ≥ 0.95` → stability is
  uninformative; the outcome is at best **inconclusive** (spectral rule still
  applies for "fails").
- `spectral_ratio ≤ 1.5` **and** `stability_agreement ≥ 0.90` → **axiom survives**. T02 is unblocked.
- `spectral_ratio > 3.0` **or** `stability_agreement < 0.70` → **axiom fails**. T02–T06 cancelled; project paused for redesign.
- Anything else → **inconclusive**. Planner writes T01b with a second replicate pair before any alignment work.

Rules are applied top to bottom; "fails" overrides "inconclusive".

### What would change my mind
If `spectral_ratio > 3.0` on a same-donor, two-chemistry pair, chemistry
alone bends local dynamics enough that operators are not a usable
batch-invariant, and the method as conceived does not work. If only
`spectral_ratio_scaled` is ≤ 1.5, the difference is a global rate scale,
which would point T02 toward a scale term; that is a reading for the next
task, not this outcome.

## Procedure

1. `t01_run.py --stage counts` — QC subset, gene intersection, HVGs,
   normalisation; write `reports/T01/genes.txt`.
2. `t01_run.py --stage operators` — PCA, scVelo, `v_pca`, JacobianField;
   write `reports/T01/ops_v2.npz`, `ops_v3.npz` (arrays: `J` (n_valid, 30, 30),
   `eig` (n_valid, 30) complex, `cell_type` str, `barcode` str).
3. `t01_run.py --stage spectral` — the four spectral numbers; write
   `reports/T01/w2_draws.csv` (columns: kind ∈ {pooled, null_v2, null_v3},
   draw, w2, w2_scaled) and `reports/T01/fig_spectra.png` (eigenvalues of
   both chemistries overlaid in the complex plane; inset histogram of null
   W2 draws with the pooled median marked).
4. `t01_run.py --stage stability` — write `reports/T01/stability_table.csv`
   (columns: cell_type, n_v2, n_v3, frac_stable_v2, frac_saddle_v2,
   frac_unstable_v2, frac_stable_v3, frac_saddle_v3, frac_unstable_v3,
   class_v2, class_v3, agree) and `reports/T01/fig_stability.png` (heatmap of
   majority class, cell type × dataset).
5. `t01_run.py --stage report` — assemble `report.json`, checksums, lockfile.

`reports/T01/scripts/t01_run.py` must also run end-to-end with `--stage all`.
