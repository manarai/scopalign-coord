# T01 — Kill test: does the operator spectrum survive a pure technical batch?

planner_commit: <fill at commit>

## Purpose

Tahoe's axiom is that batch effects change where cells are, not how they
move. The cheapest test is a dataset where the *same biological sample* was
profiled under two chemistries, so any difference is technical by
construction. If per-cell operator spectra and stability classes already
agree across the two chemistries **before any alignment**, the axiom
survives and T02–T05 proceed. If they do not, the axiom fails and the
project stops at this task.

## Scope

### In scope
- Dataset: 10x Genomics PBMC, same donor, v2 vs v3 chemistry. Use the
  pair already downloaded to `data/pbmc_v2_v3/` as `pbmc_v2.h5ad` and
  `pbmc_v3.h5ad` (planner verifies these exist in T00). No other dataset.
- Cells: all cells passing the QC already stored in `obs['qc_pass'] == True`.
  No further filtering.
- Genes: intersection of genes present in both files, then top 2000 HVGs
  computed on the **concatenated** matrix with `sc.pp.highly_variable_genes(
  flavor='seurat_v3', n_top_genes=2000, batch_key=None)`. The same gene list
  is used for both datasets.
- Normalisation: `sc.pp.normalize_total(target_sum=1e4)` then `sc.pp.log1p`.
- Positional layer: `sklearn.decomposition.PCA(n_components=30,
  random_state=20261014)` fitted **separately** on each dataset. Do not
  share loadings. (Separate fits are the point: we want to see whether the
  spectrum agrees despite separate frames.)
- Operator estimation: scJDO2 neighbourhood operator field, `k=30`,
  default kernel, one Jacobian per cell, in the 30-d PCA space.
- Matching cells across datasets for comparison: by `obs['cell_type']`
  (the harmonised labels already in both files), not by position.

### Out of scope
- Any alignment, Procrustes, CCA, Harmony, scVI, or correction of any kind.
- Any nonlinear embedding.
- Any other dataset, including other donors.
- Varying `k`, `n_components`, HVG count, or normalisation.
- Gene-level loadings / eigenvector comparison (that is T02).
- Computing anything on a subsample for the reported numbers.

## Pre-registration

### Gated numbers
| name | definition | computed by |
|------|-----------|-------------|
| `n_cells_v2` | cells passing QC in v2 | `python scripts/t01_run.py --stage counts` |
| `n_cells_v3` | cells passing QC in v3 | same |
| `spectral_w2_pooled` | 2-Wasserstein distance (POT `ot.emd2`, Euclidean on complex eigenvalues as (Re,Im) pairs) between the pooled eigenvalue clouds of v2 and v3 | `python scripts/t01_run.py --stage spectral` |
| `spectral_w2_null` | median of 200 within-dataset split-half 2-Wasserstein distances (v2 vs v2, v3 vs v3, pooled), seed 20261014 | same |
| `spectral_ratio` | `spectral_w2_pooled / spectral_w2_null` | same |
| `stability_agreement` | fraction of cell types (n ≥ 50 cells in both datasets) whose majority stability class (stable / saddle / unstable, by sign pattern of real parts) is the same in v2 and v3 | `python scripts/t01_run.py --stage stability` |
| `n_cell_types_tested` | number of cell types meeting the n ≥ 50 rule | same |

### Decision rule
- `spectral_ratio ≤ 1.5` **and** `stability_agreement ≥ 0.90` → **axiom survives**. T02 is unblocked.
- `spectral_ratio > 3.0` **or** `stability_agreement < 0.70` → **axiom fails**. T02–T06 cancelled; project paused for redesign.
- Anything between → **inconclusive**. Planner writes T01b with a second replicate pair before any alignment work.

### What would change my mind
If `spectral_ratio > 3.0` on a same-donor, same-tissue, two-chemistry pair,
then chemistry alone bends local dynamics enough that operators are not a
usable batch-invariant, and the method as conceived does not work.

## Procedure

1. `scripts/t01_run.py --stage counts` — load both files, apply gene
   intersection + HVG + normalisation, write `reports/T01/genes.txt`,
   record `n_cells_v2`, `n_cells_v3`.
2. `scripts/t01_run.py --stage operators` — PCA(30) per dataset, scJDO2
   operator field, write `reports/T01/ops_v2.npz`, `reports/T01/ops_v3.npz`
   (arrays: `J` shape (n_cells, 30, 30), `eig` shape (n_cells, 30) complex,
   `cell_type` str).
3. `scripts/t01_run.py --stage spectral` — compute `spectral_w2_pooled`,
   `spectral_w2_null`, `spectral_ratio`; write
   `reports/T01/fig_spectra.png` (two overlaid eigenvalue scatterplots in
   the complex plane, v2 vs v3, with the null distribution of W2 as an inset
   histogram and the pooled value marked).
4. `scripts/t01_run.py --stage stability` — per cell type majority stability
   class in each dataset; write `reports/T01/stability_table.csv`
   (columns: cell_type, n_v2, n_v3, class_v2, class_v3, agree) and
   `reports/T01/fig_stability.png` (a heatmap of class per cell type × dataset).
5. `scripts/t01_run.py --stage report` — assemble `report.json`, checksums,
   lockfile.

`scripts/t01_run.py` is written by the executor under `reports/T01/scripts/`.
It must accept `--stage` and be runnable end-to-end with `--stage all`.
