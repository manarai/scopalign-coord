## Amendment log

- 2026-10-14 (before any data was staged): `device="cpu"` added for

## Purpose

Same donor, same PBMCs, two 10x chemistries. Any difference is technical
by construction. If per-cell-type eigenvalue spectra and `basin_index`
agree across v2 and v3 **before any alignment**, the scOpAlign axiom
survives and T02 proceeds. If they do not, the axiom fails and the project
stops here.

## Scope

### In scope
- Latents: `reports/T00b/latent_fa_v2.npy` and `latent_fa_v3.npy` (or the
  LDVAE latents if T00b selected LDVAE; the planner edits this line on
  T00b ACCEPT and records which). `d = 30`.
- Cells and labels: as in T00b; `obs['cell_type']` from the staged files.
- Drift: `scjdo2.energy_drift.EnergyDriftAdapter` with
  `EnergyDriftConfig(hidden=96, depth=3, n_epochs=1500, seed=20261014,
  batch_size=256, loss="esm", lr=5e-4, beta=1.0, esm_laplacian="hutchinson",
  device="cpu")`,
  fit **separately** on each dataset's latent. (These are the values used
  by scJDO2's `scripts/basin_classify_latent.fit_energy_drift`.)
- Operators: `drift.jacobian_autodiff(z)` → `(n, 30, 30)` per dataset.
  Run `drift.symmetry_check(z, n_cells=100)` and record it.
- Basin call: `scjdo2.opspace.classify_basin_latent(adata, tol=tol,
  use_rep="X_latent", rule="lead_eig")` with
  `tol = 0.1 × median |λ|` over all eigenvalues of all cells in **that
  dataset** (dataset-specific oracle tol, as in scJDO2 §5.7 item 3).
- Comparison unit: cell types with ≥ 50 cells in **both** datasets.

### Out of scope
- Any alignment, Procrustes, CCA, Harmony, scVI, or correction.
- Gene-space Jacobians (Phase C).
- Varying `d`, drift hyperparameters, tol rule, or the cell-count floor.
- Any other dataset.
- Subsampling for the reported numbers, other than the pre-registered
  W2 draws below.

## Pre-registration

W2 convention: eigenvalues are real, so
`W2(x, y) = sqrt(ot.wasserstein_1d(x, y, p=2))` with uniform weights.
Draws use one `numpy.random.default_rng(20261014)`, consumed in the
order below. For each tested type `t`, `m_t = floor(min(n_v2_t, n_v3_t) / 2)`.
A **pooled draw**: for each `t`, sample `m_t` cells of `t` from v2 and `m_t`
from v3 without replacement; W2 between their pooled eigenvalues (all 30
per cell); mean over types. A **null draw** on dataset D: for each `t`,
sample `2·m_t` cells of `t` from D without replacement, split at random
into two halves of `m_t`; W2 between halves; mean over types. Both sides
of every W2 therefore have the same number of cells.

### Gated numbers
| name | definition | computed by |
|------|-----------|-------------|
| `n_cell_types_tested` | cell types meeting the ≥ 50 rule | `python reports/T01/scripts/t01_run.py --stage compare` |
| `symmetry_v2` | `‖J − Jᵀ‖_F / ‖J‖_F` median over 100 cells, v2 | `--stage operators` |
| `symmetry_v3` | same, v3 | same |
| `spectral_w2_pooled` | median over 200 pooled draws | `--stage compare` |
| `spectral_w2_null` | median over 200 null draws (100 on v2, then 100 on v3) | same |
| `spectral_ratio` | `spectral_w2_pooled / spectral_w2_null` | same |
| `basin_index_rho` | Spearman ρ between per-cell-type median `basin_index` in v2 and in v3 across tested types | same |
| `basin_class_agreement` | fraction of tested types whose majority `op_behaviour_basin` is the same in v2 and v3 | same |

### Decision rule
- `spectral_ratio ≤ 1.5` **and** `basin_index_rho ≥ 0.80` **and**
  `basin_class_agreement ≥ 0.90` → **axiom survives**; T02 unblocked.
- `spectral_ratio > 3.0` **or** `basin_index_rho < 0.50` → **axiom
  fails**; T02–T06 cancelled; project paused for redesign.
- Anything between → **inconclusive**; planner writes T01b with a second
  technical-replicate pair before any alignment work.
- Independently: if `symmetry_v2` or `symmetry_v3` > 1e-4 → REVISE (the
  drift fit is wrong, regardless of the other numbers).

### What would change my mind
`spectral_ratio > 3.0` on a same-donor, two-chemistry pair means chemistry
alone reshapes the local wells enough that basin operators are not a usable
batch invariant, and scOpAlign as conceived does not work.

## Procedure

1. `t01_run.py --stage drift` — fit the energy drift per dataset; save
   `drift_v2.pt`, `drift_v3.pt` (kept locally, not deliverables).
2. `t01_run.py --stage operators` — Hessians, symmetry checks; write
   `ops_v2.npz`, `ops_v3.npz` (arrays: `J` (n,30,30), `eig` (n,30) real,
   `cell_type` str).
3. `t01_run.py --stage basin` — tol per dataset, `classify_basin_latent`;
   write `basin_table.csv` (cell_type, n_v2, n_v3, median_bi_v2,
   median_bi_v3, class_v2, class_v3, agree).
4. `t01_run.py --stage compare` — all gated numbers; write
   `fig_spectra.png` (per-type eigenvalue density, v2 vs v3 overlaid, one
   small panel per tested type, plus null histogram inset with pooled
   value marked) and `fig_basin.png` (scatter of per-type median
   basin_index v2 vs v3 with identity line and ρ in the title).
5. `t01_run.py --stage report` — `report.json`, checksums, lockfile.

`t01_run.py` must accept `--stage all`.
