# K3 — Gene-network space from archetype operators: batch-robust and biology-informative?

status: pre-registered (2026-10-20; Tom: "proceed with testing", feasibility of a network space derived from archetypes)
blocked_by: none; platform: the **Manus cloud sandbox used for T04/T04b** (needs T04's cache); start after T04b's sweep has finished (CPU)
seed: 20261014
planner_commit: 5aa6b72
kind: diagnostic (feasibility; no alignment, no correction)
motivated_by: Tom's idea — map each archetype's operator into gene space (genes are named in every batch, so no rotation is needed) and use that network space for alignment. Before any alignment, test whether the space is stable across batches and sensitive to biology.

## Purpose

For each cell type (archetype) and copy, build a gene–gene network from the
operator, `N = Wᵀ C W` (2000 × 2000; `C` = 30 × 30 centroid operator, `W` =
that copy's 30 × 2000 PCA loadings). Ask four questions, each as a ratio to
refit noise:

1. **Technical batch** (two halves of one run): does `N` change? (want ≈ 1)
2. **Gene-level batch** (T04's S0 batch, no biology): does `N` change? (want ≈ 1)
3. **Cell type** (monocytes vs T cells, same copy): does `N` differ? (want ≫ 1)
4. **Biology** (T04 S1: interferon responders vs non-responders, inside B):
   does `N` differ? (want > 1)

The same four ratios are computed for a plain baseline: each group's
**gene correlation network** from its expression (no operators). If the
operator network is no better than the correlation network, operators add
nothing here.

## Scope

### In scope
- **Pair P1 — technical halves:** K0 halves (`reports/K0/latent_pca30_h1.npy`,
  `_h2.npy`; loadings re-derived exactly as K0: genes.txt subset,
  `normalize_total(1e4)`, `log1p`, `PCA(30, svd_solver="full",
  random_state=20261014)`; record `latent_check` vs the committed latents,
  relative criterion as C0 amendment 1). **10 new drift fits**: T04's
  `drift_config`, seeds 20261014, 20261016–19, per half. Types: coarse
  `cell_type` with ≥ 100 cells in both halves.
- **Pair P2 — gene-level batch (T04 S0):** T04's cached `z_a`, `z_b`, `w_a`,
  `w_b`, fits and per-cell operators (read-only, sha256 recorded). Types as
  P1. B monocytes are one group (no biology in S0).
- **Biology (T04 S1, B only):** responders vs non-responding monocytes, from
  T04's S1 cache.
- **Operator network:** per group, seed `t`: `C_t = centroid_operator(z,
  M_t, n_cells_centroid=30)` (float64, symmetric part), `N_t = Wᵀ C_t W`.
- **Correlation network (baseline):** per group, Pearson correlation of the
  group's log-normalised expression over the 2000 genes (genes with zero
  variance in the group set to 0 correlation; recorded).
- **Distance:** `d(N₁, N₂) = ‖N₁ − N₂‖_F / ‖N₂‖_F` (T04's `residual`).
- **Refit / sampling null (per group):** operator networks — random half
  splits of the group's cells × seed pairs (20261014 vs each of 20261016–19),
  5 splits per pair (`default_rng(20261300)`), median of 20; correlation
  networks — 20 random half splits, median.
- **Ratios (each = observed `d` ÷ the null of the second group):**
  - `tech`: H1 vs H2, same type, seed 20261014 (per type; median over types);
  - `genebatch`: A vs B (S0), same type (per type; median);
  - `type`: Monocytes vs T cells within H2 (P1) — one value;
  - `bio`: responders vs non-responders within B (S1) — one value.
  Correlation networks: same comparisons (no seeds).
- **Figure:** `fig_network_ratios.png` — the four ratios for both network
  kinds, with lines at 1.5 and 3.

### Out of scope
- Any alignment or correction in network space (that would follow only if
  this passes); TF/motif priors; other genes, centroid sizes, seeds.

### Decision rule
0. Validity: `n_types_P1 < 3`, `latent_check_rel > 1e-4` or
   `symmetry_max > 1e-4` → REVISE.
1. **batch_sensitive** if `net_ratio_tech > 2.0` or `net_ratio_genebatch > 2.0`.
2. Else **uninformative** if `net_ratio_type < 3.0` or `net_ratio_bio < 1.5`.
3. Else **no_better_than_correlation** if the correlation network is at
   least as good on every criterion (`corr_ratio_tech ≤ net_ratio_tech`,
   `corr_ratio_genebatch ≤ net_ratio_genebatch`, `corr_ratio_type ≥
   net_ratio_type`, `corr_ratio_bio ≥ net_ratio_bio`).
4. Else **promising** — network-space alignment may be designed next.

### What would change my mind
If the operator network changes as much between two halves of one run as
between monocytes and T cells, network space is too noisy to align in; if
it is batch-robust but blind to the interferon response, it could align
batches but would not tell biology apart.

## Procedure

1. `--stage fits` — P1 loadings, 10 fits (cached, resumable), per-cell
   operators for P1; input checks for P2 and S1.
2. `--stage compare` — networks, nulls, ratios; `ratios.csv` (pair,
   comparison, network_kind, type, observed, null, ratio).
3. `--stage report` — figure, `report.json`, checksums, lockfile.

`--stage all`; detached, resumable; branch `task/K3` from `main` in the T04
clone; push after each stage. Networks are 2000 × 2000 float64 per group and
seed — compute distances on the fly, do not store them all.
