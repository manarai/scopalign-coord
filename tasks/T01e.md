## Purpose

T01, T01c and T01d (v2 vs v3) were all inconclusive by the separation guard,
while every between-chemistry ratio sat far above 3. This task asks the
question underneath: **do scJDO2 basin operators even reproduce across two
runs of the same chemistry on the same donor's cells?** 10x's
`pbmc_1k_v3` and `pbmc_10k_v3` were generated from the same donor's PBMCs,
both with v3 chemistry. Cell count and depth are matched per cell type, and
the T01d pipeline and decision rule are applied unchanged.

What each outcome means for the project (planner reading, decided now):
- **survives** → operators reproduce across runs within a chemistry; the
  v2/v3 difference in T01–T01d is a chemistry effect, and the axiom as
  written fails for chemistry changes.
- **fails** → operators do not reproduce even within a chemistry; the
  operator estimate itself is unstable at this sample size, and the
  v2/v3 results say nothing about chemistry.
- **inconclusive** → the separation guard blocks again; the test design
  (4 types, ~1000 cells) is too weak to decide, and that is itself the
  finding to take to redesign.

No earlier task's outcome changes.

## Scope

### In scope
- **Dataset A:** `data/pbmc_v2_v3/pbmc_v3.h5ad` (staged by T00; the 1k v3
  run), QC cells only (1113), original counts (not the T01d thinned file).
- **Dataset B, staging:** download
  `https://cf.10xgenomics.com/samples/cell-exp/3.0.0/pbmc_10k_v3/pbmc_10k_v3_filtered_feature_bc_matrix.h5`
  to `data/pbmc_10k_v3/raw/`; record its sha256. Build
  `data/pbmc_10k_v3/pbmc_10k_v3.h5ad` exactly as T00 built the v2/v3 files
  (raw integer counts, gene symbols, `var_names_make_unique()`,
  `var['gene_ids']`; `qc_pass` = `n_genes_by_counts ≥ 200` and
  `pct_counts_mt < 20`; `cell_type` from CellTypist `Immune_All_High.pkl`,
  `majority_voting=False`, on a `normalize_total(1e4)` + `log1p` copy, all
  cells).
- **Cell-count matching (B only):** for every cell type present in A, draw
  from B's QC cells of that type, without replacement, as many cells as A
  has (all of B's cells if B has fewer). B cells of types absent from A are
  dropped. One `numpy.random.default_rng(20261014)`; types in sorted order;
  within a type, `rng.choice` over B's QC cells of that type in file order.
  The drawn cells, in B's file order, are "B-sub".
- **Depth matching (both directions, per cell type):** depth = total UMI per
  cell over all genes. For each cell type present in both A and B-sub,
  the dataset with the higher median depth for that type is thinned to the
  other's depth distribution for that type, with T01d's rule: quantile
  targets (`q = (r − 0.5)/n`, ranks by depth, ties by barcode,
  `numpy.quantile(method="linear")`), `p_c = min(1, target/depth)`,
  `Binomial(x, p_c)` on each count, cells in file order and nonzeros in CSR
  order, cells with `p_c = 1` unchanged and consuming no draws. A new
  `numpy.random.default_rng(20261015)`; thin A's cells first (types in
  sorted order), then B-sub's. Write `data/pbmc_10k_v3/A_matched.h5ad` and
  `data/pbmc_10k_v3/B_matched.h5ad`.
- **Genes, FA, operators, draws:** exactly as `tasks/T01d.md` (both-
  chemistry gene filter, ≥ 3 cells each; **genes sorted alphabetically
  before** `highly_variable_genes(flavor='seurat_v3', n_top_genes=2000,
  batch_key=None)` on the concatenated raw counts, and the selected list
  kept in that sorted order; `normalize_total(1e4)` + `log1p`;
  `FactorAnalysis(30, random_state=20261014, max_iter=2000)` per dataset;
  tangent rank; drift config; Jacobians; symmetry check;
  `classify_basin_latent` with dataset-specific tol; tested types (≥ 50
  cells in both); `m_t`; all draws on `default_rng(20261014)` in T01c's
  order; all W2/W1/TV definitions; ratio convention), with A in the role of
  v2 and B-sub in the role of v3.

### Out of scope
- Any v2 data, the T01d thinned file, or reusing any earlier latent or
  operator.
- Other 10x runs, other annotation models, relabelling, re-QC after
  thinning.
- Changing any threshold, count, seed, draw or rule.

### Decision rule
Applied top to bottom; the first matching line decides.
0. **Validity** (not outcomes): `count_match_max_abs > 0`,
   `depth_match_max_rel > 0.05`, `n_hvg_zero_a > 0` or `n_hvg_zero_b > 0` →
   **REVISE**. FA not admissible by T00c's rule (median rank ≥ 10 in both,
   gap ≤ 5, ceiling ≤ 0.20) → **inconclusive** (stop).
1–6. T01c's rule, unchanged, with A/B in place of v2/v3: symmetry > 1e-4 →
   REVISE; `n_cell_types_tested < 3` → inconclusive; any `*_sep_*` < 2 →
   inconclusive; `spectral_ratio > 3.0` or `basin_ratio > 3.0` →
   **fails** (operators do not reproduce within chemistry);
   `spectral_ratio ≤ 1.5` and `basin_ratio ≤ 1.5` and `class_tv_ratio ≤ 1.5`
   → **survives** (operators reproduce within chemistry); otherwise
   inconclusive.

(`count_match_max_abs > 0` can only happen if B has fewer cells of a tested
type than A; if so the planner revises the task, not the data.)

### What would change my mind
`spectral_ratio > 3.0` on two v3 runs of the same donor's cells at matched
count and depth means the operator estimate is not reproducible across
runs, and no batch-alignment claim can rest on it.

   `draws.csv`, `fig_spectra.png`, `fig_basin.png`.
