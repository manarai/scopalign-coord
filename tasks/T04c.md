status: pre-registered (2026-10-20; Tom chose option B first, then T04b, then real stimulated data)
blocked_by: none (T04 ACCEPT); platform: the **same Manus cloud sandbox** as T04 (uses its cache)

planner_commit: 8f1b7e6
kind: follow-up (diagnostic; cheap, no new fits)
motivated_by: reports/T04/REVIEW.md — the cross-batch operator flag failed because the gene-level batch effect itself changes monocyte operators (S0 flagged 2.42); a comparison made **inside one batch** cannot see the batch at all

## Purpose

Ask the narrowest question left about the operators: **inside batch B, do
interferon responders have different operators from non-responding
monocytes, beyond refit noise?** Both groups share B's fit, frame and batch
effect, so any difference is biology (S1) or nothing (S0). If operators do
not see the biology here, they cannot flag it anywhere; if they do, they
can serve as a biology detector next to a rigid correction.

## Scope

### In scope
- **Inputs (T04 cache in the sandbox, read-only):** S0 and S1 embeddings
  (`cache/embeddings/`), B's drift fits (5 seeds per scenario) and B's
  per-cell operators (`cache/operators/`, computed by T04's flag stage;
  recompute with T04's `operator()` if absent). Import T04's script by path;
  write nothing under `reports/T04/`.
- **Input check:** recompute `fit_symmetry` for the B fits used and compare
  with T04's committed `fit_symmetry.csv` (must match exactly).
- **Groups (B only):** `R` = B responders (S0: the same cells, pseudo-
  responders), `N` = B monocytes not in `R`. Sanity contrast: B `Monocytes`
  vs B `T cells`.
- **Operator contrast, per seed `t` ∈ (20261014, 20261016–19):**
  `Δ_t = residual(C_t(R), C_t(N))` with T04's `residual` and
  `centroid_operator(z, M_t, n_cells_centroid=30)` on B's latent `z_B`
  (no rotation: one frame). `contrast = median_t Δ_t`.
- **Null (relabelling, same fit):** for each seed `t`, 20 random relabellings
  of `R ∪ N` into groups of sizes `|R|`, `|N|`
  (`numpy.random.default_rng(20261200)`, seeds in order, relabellings in
  order); `Δ'` as above; `null = median` over all 100.
  `contrast_ratio = contrast / null`. Per-seed ratio `Δ_t / median_null_t`.
- **Same for the sanity contrast** (Monocytes vs T cells; relabelling of
  their union) → `type_ratio`.
- **Position baseline:** `pos = ‖mean z_B[R] − mean z_B[N]‖`, null by the
  same relabellings → `pos_ratio` (biology visible in positions?).
- **Figure:** `fig_contrast.png` — per-seed contrast ratios for S1 and S0
  with the null band, plus `type_ratio` and `pos_ratio`.

### Out of scope
- New drift fits; other groups, centroid sizes, relabelling counts or
  seeds; anything across batches.

## Pre-registration

### Gated numbers

### Decision rule
0. Stop / validity: `inputs_match = 0` → status `"stopped"`
   (`stop_rule: "inputs_mismatch"`); do not refit. `type_ratio_S1 < 2.0`
   (operators cannot tell monocytes from T cells) or `symmetry_max > 1e-4`
   → REVISE.
1. **detects** if `contrast_ratio_S1 ≥ 2.0`, `contrast_ratio_S0 ≤ 1.5` and
   `seed_agreement_S1 ≥ 0.8`.
2. **no_detect** if `contrast_ratio_S1 ≤ 1.5`.
3. Otherwise **weak**.
- Reading: `pos_ratio_S1` ≫ 2 with `no_detect` means the response moves
  cells without reshaping their landscape — positions see it, operators do
  not.

### What would change my mind
If operators fail to separate responders inside a single batch while
positions separate them clearly, operator-level information is not a
useful biology detector for this kind of change, and the project proceeds
with the rigid correction alone (T04b, then real data).
