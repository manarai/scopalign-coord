## Purpose

Same donor, same PBMCs, two 10x chemistries. Any difference is technical
by construction. If per-cell-type eigenvalue spectra and `basin_index`
agree across v2 and v3 **before any alignment**, the scOpAlign axiom
survives and T02 proceeds. If they do not, the axiom fails and the project
stops here.

## Pre-registration

W2 convention: eigenvalues are real, so
`W2(x, y) = sqrt(ot.wasserstein_1d(x, y, p=2))` with uniform weights.
Draws use one `numpy.random.default_rng(20261014)`, consumed in the
order below. For each tested type `t`, `m_t = floor(min(n_v2_t, n_v3_t) / 2)`.
A **pooled draw**: for each `t`, sample `m_t` cells of `t` from v2 and `m_t`
from v3 without replacement; W2 between their pooled eigenvalues (all 30
per cell); mean over types. A **null draw** on dataset D: for each `t`,
sample `2·m_t` cells of `t` from D without replacement, split at random
into two halves of `m_t`; W2 between halves; mean over types. Both sides
of every W2 therefore have the same number of cells.

On the **same sampled cells** of every pooled and null draw, also compute,
per type, then mean over types:
- basin distance `W1 = ot.wasserstein_1d(x, y, p=1)` on per-cell
  `op_basin_index` (uniform weights);
- class distance `TV = ½ Σ_c |p_x(c) − p_y(c)|` over the categories of
  `op_behaviour_basin` (`holder`, `fork`, `drift`, and the empty
  unclassified category as its own class).

A **separation draw** on dataset D: for each unordered pair of tested types
`(a, b)`, `m = min(m_a, m_b)`; sample `m` cells of `a` and `m` of `b` from D
without replacement; spectral W2 and basin W1 between them; mean over pairs.

Draw order on the single generator: 200 pooled; 100 null on v2; 100 null
on v3; 100 separation on v2; 100 separation on v3.

Ratio convention: `ratio = median(pooled) / median(null)`. If the null
median is 0, the ratio is 1.0 when the pooled median is also 0, otherwise
`inf`.

### Gated numbers
| name | definition | computed by |
|------|-----------|-------------|
| `n_cell_types_tested` | cell types meeting the ≥ 50 rule | `python reports/T01c/scripts/t01c_run.py --stage compare` |
| `symmetry_v2` | `‖J − Jᵀ‖_F / ‖J‖_F` median over 100 cells, v2 | `--stage operators` |
| `symmetry_v3` | same, v3 | same |
| `spectral_w2_pooled` | median over 200 pooled draws | `--stage compare` |
| `spectral_w2_null` | median over 200 null draws (100 on v2, then 100 on v3) | same |
| `spectral_ratio` | `spectral_w2_pooled / spectral_w2_null` | same |
| `basin_w1_pooled` | median basin W1 over the 200 pooled draws | same |
| `basin_w1_null` | median basin W1 over the 200 null draws | same |
| `basin_ratio` | `basin_w1_pooled / basin_w1_null` | same |
| `class_tv_pooled` | median class TV over the 200 pooled draws | same |
| `class_tv_null` | median class TV over the 200 null draws | same |
| `class_tv_ratio` | `class_tv_pooled / class_tv_null` | same |
| `spectral_sep_v2` | median spectral W2 over the 100 separation draws on v2 ÷ median spectral W2 over the 100 null draws on v2 | same |
| `spectral_sep_v3` | same for v3 | same |
| `basin_sep_v2` | median basin W1 over the 100 separation draws on v2 ÷ median basin W1 over the 100 null draws on v2 | same |
| `basin_sep_v3` | same for v3 | same |
| `basin_index_rho` | *secondary, not in the decision rule:* Spearman ρ between per-type median `basin_index` in v2 and v3 across tested types | same |
| `basin_class_agreement` | *secondary, not in the decision rule:* fraction of tested types whose majority `op_behaviour_basin` is the same in v2 and v3 | same |

### Decision rule
Applied top to bottom; the first matching line decides.
1. `symmetry_v2` or `symmetry_v3` > 1e-4 → **REVISE** (the drift fit is
   wrong; not an outcome).
2. `n_cell_types_tested < 3` → **inconclusive**.
3. Any of `spectral_sep_v2`, `spectral_sep_v3`, `basin_sep_v2`,
   `basin_sep_v3` < 2 → **inconclusive** (operators do not distinguish cell
   types, so agreement is uninformative).
4. `spectral_ratio > 3.0` **or** `basin_ratio > 3.0` → **axiom fails**;
   T02–T06 cancelled; project paused for redesign.
5. `spectral_ratio ≤ 1.5` **and** `basin_ratio ≤ 1.5` **and**
   `class_tv_ratio ≤ 1.5` → **axiom survives**; T02 unblocked.
6. Anything else → **inconclusive**; planner writes T01b with a second
   technical-replicate pair before any alignment work.

`basin_index_rho` and `basin_class_agreement` are reported and recomputed
but never change the outcome.

### What would change my mind
`spectral_ratio > 3.0` or `basin_ratio > 3.0` on a same-donor,
two-chemistry pair, with operators that do separate cell types, means
chemistry alone reshapes the local wells enough that basin operators are not a usable
batch invariant, and scOpAlign as conceived does not work.

## Procedure

1. `t01c_run.py --stage drift` — fit the energy drift per dataset; save
   `drift_v2.pt`, `drift_v3.pt` (kept locally, not deliverables).
2. `t01c_run.py --stage operators` — Hessians, symmetry checks; write
   `ops_v2.npz`, `ops_v3.npz` (arrays: `J` (n,30,30), `eig` (n,30) real,
   `cell_type` str).
3. `t01c_run.py --stage basin` — tol per dataset, `classify_basin_latent`;
   write `basin_table.csv` (cell_type, n_v2, n_v3, median_bi_v2,
   median_bi_v3, class_v2, class_v3, agree).
4. `t01c_run.py --stage compare` — all gated numbers; write `draws.csv`
   (columns: kind ∈ {pooled, null_v2, null_v3, sep_v2, sep_v3}, draw,
   spectral_w2, basin_w1, class_tv; `class_tv` empty for sep rows), and
   `fig_spectra.png` (per-type eigenvalue density, v2 vs v3 overlaid, one
   small panel per tested type, plus null histogram inset with pooled
   value marked) and `fig_basin.png` (scatter of per-type median
   basin_index v2 vs v3 with identity line and ρ in the title).
5. `t01c_run.py --stage report` — `report.json`, checksums, lockfile.

`t01c_run.py` must accept `--stage all`.
