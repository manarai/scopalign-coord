## Purpose

T02 stopped: only 1 of 20 starts reached the best rotation, and the fitted
rotation did not carry over to a held-out cell type. Four type-mean
operators are too few constraints for a 30-d rotation. T02b keeps T02's
estimator and rule and adds two things:

1. **More correspondences:** finer cell-type labels (CellTypist
   `Immune_All_Low`), so the rotation is fitted to many matched groups
   instead of four.
2. **An independent anchor:** both datasets' PCAs are built on the same
   2000 genes, so their loadings give a rotation between the two frames
   that uses no operators at all (`Q_load`). It is a 21st starting point
   and a comparator: if the operator-based rotation agrees with it, the
   operators carry the same frame information as the gene loadings.

- **frame agreement** → T04 next.
- **no frame agreement** or **inconclusive** → planner brings the numbers
  to Tom.

## Scope

### In scope
- **Inputs (record sha256 of each):** as T02 — `reports/K2/latent_pca30_a.npy`,
  `reports/K2/latent_pca30_b.npy`, `reports/K2/ops_a.npz`,
  `reports/K2/ops_b.npz`, `data/pbmc_v2_v3/k2_cells.csv`,
  `data/pbmc_v2_v3/pbmc_v2.h5ad`, `data/pbmc_v2_v3/pbmc_v3.h5ad`,
  `data/pbmc_v2_v3/pbmc_v3_thin.h5ad`, `reports/T01d/genes.txt`. A =
  matched v2, B = matched v3-thin, cells in K2's order.
- **Fine labels:** CellTypist `Immune_All_Low.pkl`
  (`celltypist.models.download_models(model="Immune_All_Low.pkl")`, model
  cache under `data/pbmc_v2_v3/celltypist_home` as in T00),
  `majority_voting=False`, run on **original** counts: `pbmc_v2.h5ad` and
  `pbmc_v3.h5ad`, all cells, each normalised with `normalize_total(1e4)` +
  `log1p` over all genes (T00's convention). Map to K2's matched cells by
  barcode. Write `data/pbmc_v2_v3/fine_labels.csv` (barcode, dataset,
  fine_label).
- **Groups:** fine labels with **≥ 40 cells in A and ≥ 40 cells in B**,
  sorted by name. Weight `w_g = min(n_A,g, n_B,g) / Σ_g min(n_A,g, n_B,g)`.
- **PCA loadings (re-derived, must match K2):** per dataset, subset the
  matched cells to the 2000 genes, `normalize_total(1e4)`, `log1p`,
  `PCA(30, svd_solver="full", random_state=20261014)`; the scores must equal
  K2's latents (`latent_maxdiff`); keep `components_` as `W_A`, `W_B`
  (30 × 2000).
- **Gene-loading rotation:** `G = W_B · W_Aᵀ` (30 × 30); `U, σ, Vᵀ = svd(G)`;
  `Q_load = U Vᵀ`. Report `subspace_min_sv = min σ` (1 = same 30-d gene
  subspace, 0 = a missing direction).
- **Operators:** as T02 — drift fits for seeds 20261014, 20261016,
  20261017, 20261018, 20261019 on each K2 latent (ten fits), K2's config,
  `M_c = ½(J_c + J_cᵀ)` in float64; K2 reproduction check on the
  seed-20261014 restricted eigenvalues. Group-mean operators `M̄_g` from the
  seed-20261014 fits.
- **Estimator:** T02's, unchanged, on the groups:
  `L(Q) = Σ_g w_g ‖Q M̄_g^A Qᵀ − M̄_g^B‖_F² / Σ_g w_g ‖M̄_g^B‖_F²`;
  `Q = Q₀ · matrix_exp(S − Sᵀ)`; torch float64 CPU; LBFGS(lr=1,
  max_iter=500, tolerance_grad=1e-10, tolerance_change=1e-12,
  line_search_fn="strong_wolfe"); **21 starts:** `Q₀ = I`, `Q₀ = Q_load`,
  and `ortho_group.rvs(dim=30, random_state=20261021 + i)` for `i = 1…19`,
  in that order. `Q̂` = lowest final loss.
- **Residuals, null, held-out, positional comparator:** as T02, on groups
  instead of types: `resid(Q) = sqrt(L(Q))`; null = eight half-split
  alignments (A then B; seed pairs (20261014, 20261016…19);
  `default_rng(20261022)`; per group in sorted order `permutation`, halves of
  `⌊n_g/2⌋`), same estimator with the same 21-start rule (the `Q_load`
  start is replaced by `I` for the null, since both halves share one
  frame); held-out = leave one group out, mean held-out residual over
  groups; `Q_pos` = Procrustes on group centroids.
- **Views:** T02's three views, UMAP parameters and scores, with `Q̂`.

### Out of scope
- Any other label model, majority voting, relabelling or regrouping rule;
  any other estimator, weighting, threshold or seed.
- Using `Q_load` (or `Q_pos`) as the alignment; they are a start and
  comparators only.
- Re-matching, re-thinning, new separate PCAs, other datasets, any local map.

### Decision rule
Top to bottom; first match decides. Stops reported as `"status": "stopped"`.
0. **Validity:** `n_cells_a ≠ n_cells_b`, `latent_maxdiff > 1e-4`,
   `k2_repro_max_abs > 1e-5` or `symmetry_max > 1e-4` → **REVISE**.
   `n_groups < 6` → **inconclusive (stop)** (not enough correspondences).
   `n_starts_near_best < 2` → **inconclusive (stop)**.
1. `frame_ratio ≤ 1.5` **and** `heldout_ratio ≤ 1.5` → **frame agreement**.
2. `frame_ratio > 3.0` **or** `heldout_ratio > 3.0` → **no frame agreement**.
3. Otherwise → **inconclusive**.

**Secondary readings (not the outcome):** alignment helps if
`resid_aligned < resid_identity`; the operators carry the gene-loading
frame if `q_op_vs_load ≤ 0.25`; positions as in T02
(`mix_sep_A > mix_sep_noA`, `sil_sep_A ≥ 0.9 × sil_sep_noA`).

### What would change my mind
`frame_ratio` or `heldout_ratio > 3.0` with ≥ 6 matched groups and a
reproducible optimum means the v2 and v3 operator frames cannot be related
by one rotation even when the rotation is well constrained.

## Procedure

1. `t02b_run.py --stage labels` — fine labels, `fine_labels.csv`,
   `reports/T02b/group_table.csv` (fine_label, n_a, n_b, used).
2. `t02b_run.py --stage fits` — PCA re-derivation, ten drift fits (kept
   locally), K2 reproduction; `group_means.npz` (arrays: `M_bar_a`,
   `M_bar_b` (groups, 30, 30) from seed 20261014; `null_h1`, `null_h2`
   (8, groups, 30, 30) for the eight null alignments; `groups`, `w`);
   `loadings.npz` (`W_A`, `W_B`).
3. `t02b_run.py --stage align` — `Q.npy`, `Q_load.npy`, `Q_pos.npy`,
   `starts.csv`, `null.csv`, `heldout.csv`.
4. `t02b_run.py --stage views` — `umap_views.npz`, `fig_umap.png`,
   `fig_frames.png` (as T02, one line per group).
5. `t02b_run.py --stage report` — `report.json`, checksums, lockfile.

`t02b_run.py` must accept `--stage all`. (`group_means.npz` and
`loadings.npz` are saved so that the planner can recompute every alignment
number from them.)
