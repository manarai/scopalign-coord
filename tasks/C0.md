## Purpose

Manus cloud sandboxes cannot see the Mac. Before any analysis runs there,
the sandbox must rebuild the environment and every staged data file from
public sources and the committed scripts, and show that the **contents**
match the Mac's exactly (content fingerprints, `checker/fingerprint.py`).
It also measures whether the drift fit reproduces across platforms. No
scientific numbers.

## Pre-registration

### Gated numbers
| name | definition | computed by |
|------|-----------|-------------|
| `n_raw_sha_match` | of the 3 raw `.h5` files, how many match the recorded sha256 | `python reports/C0/scripts/c0_check.py` |
| `n_fingerprints_match` | of the 8 files above, how many match | same |
| `latent_check_max` | max \|re-derived − committed K0 latent\| | same |
| `drift_repro_max_abs` | max \|cloud − Mac\| restricted eigenvalue, K2 A seed 20261014 | same |
| `scjdo2_sha` | `pip show`/`git` commit of the installed scJDO2 (must start with 59cbbf3) | same |
| `platform` | `platform.platform()` | same |
| `torch_version` | `torch.__version__` | same |

### Decision rule
- `n_raw_sha_match = 3`, `n_fingerprints_match = 8`, `latent_check_max ≤
  1e-4` and `scjdo2_sha` starts with `59cbbf3` → **ACCEPT**: the cloud
  sandbox may run O-series tasks.
- `drift_repro_max_abs ≤ 1e-4` → cloud and Mac drift fits are
  interchangeable. Otherwise (still ACCEPT if the above holds): cloud
  results are valid within the cloud, but **cloud and Mac numbers are never
  mixed in one comparison**; each O-series task runs entirely on one
  platform.
- Anything else → **REVISE** (stop; do not run analysis in the cloud).
