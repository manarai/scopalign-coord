# K0 — Split-half control: which positional layer gives reproducible operators?

status: pre-registered (approved by Tom 2026-10-15)
blocked_by: none (T01e ACCEPT; redesign adopted 2026-10-15)
seed: 20261014
planner_commit: bf263d4
kind: planned (first step of the K0 → K1 → K2 ladder, PROJECT.md rule 10)

## Purpose

Two random halves of **one** run must give the same operators before any
comparison between runs or chemistries means anything. This task runs that
control for three positional layers, side by side on the same split and the
same draws, and selects the layer K1 and K2 will use (PROJECT.md rule 1):

| config | layer | spectra used |
|---|---|---|
| pca30 | `PCA(30)` | tangent-restricted, `r = 10` (rule 3a) |
| fa30 | `FactorAnalysis(30)` | tangent-restricted, `r = 10` (rule 3a) |
| fa10 | `FactorAnalysis(10)` | full 10-d spectra |

It answers three open questions at once: whether FA works in a stable
configuration (smaller `d`, or the tangent restriction); whether PCA's
operators are reproducible, not just its rank; and, by fixing a
reproducible layer, whether later K results can be verdicts on the axiom.

## Scope

### In scope
- **Data:** `data/pbmc_10k_v3/pbmc_10k_v3.h5ad` as staged in T01e (raw
  counts, `qc_pass`, `cell_type`; verified in reports/T01e/REVIEW.md).
  Record its sha256. QC cells only. No thinning (one run).
- **Split:** `rng_split = numpy.random.default_rng(20261014)`. For each cell
  type in **sorted** order: that type's QC cells in file order, `n_t` of
  them; `perm = rng_split.permutation(n_t)`; with `h = n_t // 2`, cells at
  `perm[:h]` go to H1 and `perm[h:2h]` to H2 (an odd leftover is dropped).
  Each half is then put back in file order. No other use of `rng_split`.
- **Genes (shared by all configs):** keep a gene if it has nonzero counts in
  ≥ 3 cells of H1 and ≥ 3 cells of H2. Sort the kept symbols alphabetically,
  subset both halves to that order, concatenate (H1 then H2) and run
  `sc.pp.highly_variable_genes(flavor="seurat_v3", n_top_genes=2000,
  batch_key=None)` on raw counts; keep the 2000 selected genes in
  alphabetical order (`genes.txt`). Per half: `normalize_total(1e4)` then
  `log1p` on those genes, dense.
- **Layers (per config, per half, fit separately):**
  `pca30` = `PCA(n_components=30, svd_solver="full", random_state=20261014)`;
  `fa30` = `FactorAnalysis(30, random_state=20261014, max_iter=2000)`;
  `fa10` = `FactorAnalysis(10, random_state=20261014, max_iter=2000)`.
  Scores used as is (float32 for the drift).
- **Tangent rank and basis (per config, per half):** for each cell, the
  `k = 40` nearest other cells in that latent
  (`NearestNeighbors(n_neighbors=41)`, drop the first returned neighbour,
  the cell itself); `C = np.cov(z[nbrs], rowvar=False)`;
  `w, U = np.linalg.eigh(C)`. Tangent rank = count of `w > 0.05 × w.max()`.
  For `pca30` and `fa30`: `V` = last 10 columns of `U`.
- **Drift and operators (per config, per half):**
  `EnergyDriftAdapter(dim=d, config=EnergyDriftConfig(hidden=96, depth=3,
  n_epochs=1500, seed=20261014, batch_size=256, loss="esm", lr=5e-4,
  beta=1.0, esm_laplacian="hutchinson", device="cpu")).fit(z)` with
  `d = 30` or `10`; `J = drift.jacobian_autodiff(z)`;
  `drift.symmetry_check(z, n_cells=100)`.
- **Spectra (per config, per half):** `pca30`, `fa30`:
  `λ = eigvalsh((VᵀJV + (VᵀJV)ᵀ)/2)` (10 per cell). `fa10`:
  `λ = eigvalsh((J + Jᵀ)/2)` (10 per cell). For every config:
  `basin_index = −max λ`; class `fork` if `max λ > tol`, `holder` if
  `max λ < −tol`, else `drift`, with `tol = 0.1 × median |λ|` over all
  cells of that half and config. For `pca30` and `fa30` also keep full
  30-d spectra `eigvalsh((J + Jᵀ)/2)` for the secondary number.
- **Draws (shared by all configs, so the comparison is paired):** tested
  types = types with ≥ 50 cells in both halves (the same for every config,
  since the split does not depend on the layer); `m_t = floor(min(n_H1,t,
  n_H2,t)/2)`. Draw **indices once** with a separate
  `rng_draw = numpy.random.default_rng(20261015)`, in this order: 200 pooled
  draws (each: types sorted, `rng_draw.choice` of `m_t` H1 cells; then
  types sorted, `m_t` H2 cells); 100 null draws on H1 (types sorted; per
  type `choice` of `2·m_t` cells, first `m_t` vs the rest); 100 null draws
  on H2 (same); 100 separation draws on H1 (pairs from
  `itertools.combinations` of the sorted types; per pair `choice` of
  `min(m_a, m_b)` cells of `a`, then of `b`); 100 separation draws on H2
  (same). All `choice` calls without replacement over that type's indices
  in the half's file order. Write the indices to `draw_indices.npz` and
  evaluate every config on exactly these indices.
- **Statistics (per config):** T01c's definitions with H1 in v2's role and
  H2 in v3's: W2 = `sqrt(ot.wasserstein_1d(x, y, p=2))` on pooled `λ`,
  W1 = `ot.wasserstein_1d(..., p=1)` on `basin_index`, TV over
  {"", holder, fork, drift}; mean over types (or type pairs); median over
  draws; T01c's ratio convention.

### Out of scope
- Any other layer, `d`, `k`, `r`, floor, drift setting or seed; LDVAE,
  scVI.
- Choosing among configs by anything other than the selection rule below.
- Thinning, other runs, other chemistries, any alignment, reusing earlier
  latents or operators.

### Decision rule
**Shared validity first:** `count_match_max_abs > 0` or `n_hvg_zero_h1 > 0`
or `n_hvg_zero_h2 > 0` → **REVISE**. `n_cell_types_tested < 3` → all
configs **inconclusive**, `selected_layer = "none"`, stop.

**Per config,** top to bottom, first match decides its outcome:
1. `symmetry_h1_<c>` or `symmetry_h2_<c>` > 1e-4 → **REVISE** (whole task).
2. (`pca30`, `fa30` only) `frac_rank_ge10_<c>` < 0.80 → **not supported**
   (the 10-d tangent is not there); config excluded.
3. Any `*_sep_*_<c>` < 2 → **inconclusive** (operators do not distinguish
   cell types within a half).
4. `spectral_ratio_<c>` > 3.0 **or** `basin_ratio_<c>` > 3.0 → **fails**.
5. `spectral_ratio_<c>` ≤ 1.5 **and** `basin_ratio_<c>` ≤ 1.5 **and**
   `class_tv_ratio_<c>` ≤ 1.5 → **survives**.
6. Otherwise → **inconclusive**.

**Selection** (`selected_layer`):
- If one or more configs **survive**: the first surviving one in the order
  `pca30`, `fa30`, `fa10`. (Order reason: equal reproducibility is the
  requirement; among those that meet it, PCA's orthonormal loadings give
  the simplest exact carry-back of `z ↦ A z`; `fa30` keeps `d = 30`; `fa10`
  changes `d`, which every later task would inherit.) K1 is written for it.
- If none survives and every config that was not excluded **fails** →
  `"none"`: the drift-fit operator is not reproducible within one run under
  any candidate; the ladder stops and the estimator is redesigned.
- Otherwise → `"none"`; planner brings the per-config outcomes to Tom.

### What would change my mind
If every candidate fails between two random halves of one run, the operator
is not a reproducible quantity at ~5,500 cells, whichever linear layer is
used, and no between-dataset comparison built on it can be trusted.

## Procedure

1. `k0_run.py --stage split` — split; `split_table.csv` (cell_type, n_qc,
   n_h1, n_h2); `data/pbmc_10k_v3/k0_halves.csv` (barcode, half).
2. `k0_run.py --stage latent` — genes; per config and half the latent
   (`latent_<config>_h1.npy`, `latent_<config>_h2.npy`), tangent ranks and
   bases.
3. `k0_run.py --stage drift`, `--stage operators` — six drifts (kept
   locally); `ops_<config>_<half>.npz` (arrays: `lam` (n,10), `lam_full`
   (n,30; `pca30`/`fa30` only), `basin_index`, `cls`, `cell_type`,
   `barcode`).
4. `k0_run.py --stage compare` — `draw_indices.npz`, all gated numbers,
   `basin_table.csv` (config, cell_type, n_h1, n_h2, median_bi_h1,
   median_bi_h2, class_h1, class_h2, agree), `draws.csv` (config, kind ∈
   {pooled, null_h1, null_h2, sep_h1, sep_h2}, draw, spectral_w2, basin_w1,
   class_tv, spectral_w2_full), `fig_spectra.png` (one row per config, one
   panel per tested type: eigenvalue density H1 vs H2; null-W2 inset with
   pooled median), `fig_basin.png` (one panel per config: per-type median
   basin_index H1 vs H2, identity line).
5. `k0_run.py --stage report` — `report.json`, checksums, lockfile.

`k0_run.py` must accept `--stage all`. A shared validity stop is reported
with `"status": "stopped"` (MANUS.md 8b). A config excluded or failing does
not stop the others.
