## Purpose

K2 found that, at matched count and depth, v2 and v3 basin operators agree
in their **eigenvalues** within drift-fit noise. Each dataset still has its
own PCA frame, so the operators' **eigenvectors** sit in different
coordinates. T02 estimates one orthogonal map `Q` (PROJECT.md's `A`) from
v2's frame to v3's using the operators only, asks whether the eigenvector
frames then agree within fit noise and whether `Q` generalises to a cell
type it was not fitted on, and shows the effect on cell positions
(`z ↦ Q z`) before and after.

- **frame agreement** → T04 (simulator with known batch and biology) next.
- **no frame agreement** → planner brings the numbers to Tom.
- **inconclusive** → planner brings the numbers to Tom.

## Scope

### In scope
- **Inputs, as committed or staged by K2 (record sha256 of each):**
  `reports/K2/latent_pca30_a.npy` (A = matched v2), `reports/K2/latent_pca30_b.npy`
  (B = matched v3-thin), `reports/K2/ops_a.npz`, `reports/K2/ops_b.npz`,
  `data/pbmc_v2_v3/k2_cells.csv`, `data/pbmc_v2_v3/pbmc_v2.h5ad`,
  `data/pbmc_v2_v3/pbmc_v3_thin.h5ad`, `reports/T01d/genes.txt`. No new
  PCA for the separate frames; no new matching. Cell order and labels: as
  in K2 (each matched dataset in file order; `cell_type` from its file).
- **Operators:** per dataset, refit the drift with seed 20261014 only, on
  K2's latent, with K2's config (`EnergyDriftConfig(hidden=96, depth=3,
  n_epochs=1500, seed=20261014, batch_size=256, loss="esm", lr=5e-4,
  beta=1.0, esm_laplacian="hutchinson", device="cpu")`);
  `J = jacobian_autodiff(z)` in float64; `M_c = ½(J_c + J_cᵀ)` (full 30×30)
  per cell. For the null, also refit seeds 20261016, 20261017, 20261018,
  20261019 (eight more fits).
- **K2 reproduction check:** from the seed-20261014 fits, recompute K2's
  restricted eigenvalues (K2's tangent basis rule) and compare with
  `ops_*.npz` `lam_seeds[0]`.
- **Tested types:** as K2 (≥ 50 cells in both; sorted). Type-mean operator
  `M̄_t = mean over cells of type t of M_c`, per dataset. Weights
  `w_t = n_t / Σ n_t` (n_t equal in A and B after K2's matching).
- **Estimator of Q (pre-registered: direct Frobenius minimisation, PROJECT
  rule 4):**
  `L(Q) = Σ_t w_t ‖Q M̄_t^A Qᵀ − M̄_t^B‖_F² / Σ_t w_t ‖M̄_t^B‖_F²`,
  over orthogonal 30×30 `Q`. Parametrisation `Q = Q₀ · matrix_exp(S − Sᵀ)`
  with `S` a free 30×30 matrix (torch, float64, CPU), starting at `S = 0`.
  Optimiser: `torch.optim.LBFGS(lr=1, max_iter=500, tolerance_grad=1e-10,
  tolerance_change=1e-12, line_search_fn="strong_wolfe")`, one `.step` per
  start. **Twenty starts:** `Q₀ = I` and
  `Q₀ = scipy.stats.ortho_group.rvs(dim=30, random_state=20261021 + i)`
  for `i = 1…19` (these include reflections). `Q̂` = the start with the
  lowest final loss.
- **Frame residuals:** `resid(Q) = sqrt(L(Q))`.
  `resid_identity = resid(I)`; `resid_aligned = resid(Q̂)`.
- **Null (fit noise for the same quantity):** for dataset A, then B, and for
  each `s_b` in (20261016, 20261017, 20261018, 20261019):
  `rng_null = numpy.random.default_rng(20261022)` (one generator for all
  eight, in this order); per tested type (sorted), `rng_null.permutation`
  of that type's cells, first `⌊n_t/2⌋` → half 1, next `⌊n_t/2⌋` → half 2;
  `M̄_t^{h1}` from the seed-20261014 fit on half-1 cells, `M̄_t^{h2}` from
  the `s_b` fit on half-2 cells; estimate `Q` aligning h1 → h2 with the same
  estimator and twenty starts; record `resid`. `resid_null` = median of the
  eight.
- **Held-out type:** for each tested type `t`, estimate `Q_{−t}` on the
  other types (same estimator, same starts); held-out residual
  `‖Q_{−t} M̄_t^A Q_{−t}ᵀ − M̄_t^B‖_F / ‖M̄_t^B‖_F`; `heldout_resid` = mean
  over types.
- **Positional comparator:** `Q_pos` = orthogonal Procrustes on type
  centroids: with `C^A`, `C^B` the (types × 30) centroid matrices of the
  latents, `U, Σ, Vᵀ = svd(C^Aᵀ C^B)`, `Q_pos = (U Vᵀ)ᵀ` (so `Q_pos` maps
  A-coordinates to B-coordinates as column vectors, like `Q̂`).
  `resid_pos = resid(Q_pos)`; `q_op_vs_pos = ‖Q̂ − Q_pos‖_F / sqrt(2·30)`.
- **Apply to positions:** `z_A' = z_A · Q̂ᵀ` (row vectors).
- **Three views for the before/after panels** (all cells of both matched
  datasets):
  1. **Joint PCA (uncorrected reference):** subset each matched dataset to
     the 2000 genes, `normalize_total(1e4)`, `log1p`, concatenate (A then
     B), one `PCA(30, svd_solver="full", random_state=20261014)`.
  2. **Separate PCAs, no alignment:** `[z_A ; z_B]`.
  3. **Separate PCAs, aligned:** `[z_A' ; z_B]`.
  For each view: `sc.pp.neighbors(n_neighbors=15, use_rep=<view>,
  random_state=20261014)`, `sc.tl.umap(min_dist=0.5, random_state=20261014)`.
- **Scores per view, on the 30-d representation (not the UMAP):**
  - chemistry mixing `mix` = mean over cells of the fraction of its 30
    nearest other cells (`NearestNeighbors(n_neighbors=31)`, drop the first)
    that come from the other dataset, divided by 0.5 (1 = fully mixed,
    0 = fully separated);
  - cell-type separation `sil` = `sklearn.metrics.silhouette_score`
    (Euclidean) on cells of the tested types, labels = `cell_type`.

### Out of scope
- Locally varying `Q` (T06), any non-orthogonal or scaled map, any gene-space
  lift, any other estimator (eigenvector-frame Procrustes, OT matching).
- Any other dataset; re-thinning, re-matching, new separate PCAs.
- Using UMAP coordinates for any number.

### Decision rule
Top to bottom; the first matching line decides. A stop is reported with
`"status": "stopped"` (MANUS.md 8b).
0. **Validity:** `n_cells_a ≠ n_cells_b` or `k2_repro_max_abs > 1e-5` or
   `symmetry_max > 1e-4` → **REVISE**. `n_starts_near_best < 2` →
   **inconclusive (stop)** (the optimum is not found reproducibly).
1. `frame_ratio ≤ 1.5` **and** `heldout_ratio ≤ 1.5` → **frame agreement**.
2. `frame_ratio > 3.0` **or** `heldout_ratio > 3.0` → **no frame
   agreement**.
3. Otherwise → **inconclusive**.

**Secondary readings (not the outcome):**
- alignment helps if `resid_aligned < resid_identity`;
- operator-based and position-based maps agree if `q_op_vs_pos ≤ 0.25`;
- positions: aligned view mixes better if `mix_sep_A > mix_sep_noA`, and
  keeps cell types apart if `sil_sep_A ≥ 0.9 × sil_sep_noA`;
  `mix_joint` / `sil_joint` are the uncorrected reference.

### What would change my mind
`frame_ratio > 3.0` after the best orthogonal map means that, although the
eigenvalues agree (K2), the eigenvector frames of v2 and v3 operators
cannot be brought into agreement by one rotation; a global change of basis
is not enough and alignment would need a local map (T06) or more.

## Procedure

1. `t02_run.py --stage fits` — ten drift fits (kept locally); per-cell
   `M_c` (kept locally); K2 reproduction; `type_means.npz` (`M_bar_a`,
   `M_bar_b` (types, 30, 30), `types`, `n`).
2. `t02_run.py --stage align` — `Q̂`, null, held-out, positional comparator;
   `Q.npy` (30×30), `Q_pos.npy`; `starts.csv` (start, final_loss);
   `null.csv` (dataset, seed_b, resid); `heldout.csv` (type, resid).
3. `t02_run.py --stage views` — three views, UMAPs, scores;
   `umap_views.npz` (`joint`, `sep_noA`, `sep_A` (n, 2), `dataset`,
   `cell_type`); `fig_umap.png` (3 rows = views, 2 columns = coloured by
   dataset / by cell type; each panel titled with its `mix` and `sil`);
   `fig_frames.png` (per tested type: eigenvalue-ordered absolute cosine
   between matched eigenvectors of `Q̂ M̄_t^A Q̂ᵀ` and `M̄_t^B`, top 10
   eigenvectors; one line per type; reference line for `Q = I`).
4. `t02_run.py --stage report` — `report.json`, checksums, lockfile.

`t02_run.py` must accept `--stage all`.
