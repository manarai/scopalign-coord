## Purpose

T00b chose FA, but its shared HVG list held 135 genes with zero counts in
every v2 QC cell (9 in v3). FA then gave 239 v2 genes a near-zero noise
variance, its median tangent rank was 6, and T01's operators did not
separate cell types (outcome inconclusive). This task redoes the
positional-layer choice on genes that both chemistries actually measure,
and adds a lower bound on tangent rank, which T00b's rule lacked. It
decides which latents T01c uses. T00b's result stays in FINDINGS as it was.

## Scope

### In scope
- Data: `data/pbmc_v2_v3/pbmc_v2.h5ad`, `pbmc_v3.h5ad`, cells with
  `obs['qc_pass'] == True` (992 v2, 1113 v3).
- **Gene filter (new):** keep a gene only if it is in both files and has a
  nonzero count in **≥ 3 QC cells of v2 and ≥ 3 QC cells of v3**.
- HVGs: top 2000 of the filtered genes, `sc.pp.highly_variable_genes(
  flavor='seurat_v3', n_top_genes=2000, batch_key=None)` on the
  concatenated raw counts of both datasets. **Column order: HVG symbols
  sorted alphabetically**, the same order in both datasets. Write the list
  to `reports/T00c/genes.txt`.
- Normalisation for PCA and FA: `normalize_total(target_sum=1e4)` then
  `log1p`. LDVAE: raw counts of the same 2000 genes, `batch_key=None`.
- `d = 30` for all three, each fit **separately** per dataset:
  - PCA: `sklearn.decomposition.PCA(30, random_state=20261014)`.
  - FA: `sklearn.decomposition.FactorAnalysis(30, random_state=20261014, max_iter=2000)`.
  - LDVAE: `scvi.model.LinearSCVI(n_latent=30)`, `max_epochs=250`,
    `accelerator="cpu", devices=1`, seeds `{20261014, 20261015, 20261016}`
    (`scvi.settings.seed = S` before each fit).
- Tangent rank per cell: the `k = 40` nearest other cells in latent (self
  excluded); eigenvalues of their sample covariance (`np.cov`, no added
  regulariser); rank = number of eigenvalues `> 0.05 × λ_max`.
- FA noise check: from each FA fit, count genes with
  `noise_variance_ < 1e-6`.

### Out of scope
- Any drift fit, Hessian or operator.
- Other values of the detection threshold (3 cells), HVG count, `d`, `k`
  or the floor fraction.
- Any batch-aware HVG selection (`batch_key`), scVI with a nonlinear
  decoder, or any alignment.
- Re-running or editing T00b's outputs.

### Decision rule
A layer is **admissible** if, in both datasets, its median tangent rank is
**≥ 10**, the two datasets' medians differ by **≤ 5**, and its fraction at
the ceiling (rank ≥ 28) is **≤ 0.20**.

1. `n_hvg_zero_v2 > 0` or `n_hvg_zero_v3 > 0` → **REVISE** (the gene filter
   was not applied; not an outcome).
2. FA admissible → **FA** is the positional layer for T01c.
3. Otherwise LDVAE admissible → **LDVAE** (seed 20261014) is the positional
   layer for T01c.
4. Otherwise → **no admissible linear layer**; T01c is not issued; planner
   brings the project back to Tom for redesign.

PCA is reported as a comparator only and is never selected (PROJECT.md
rule 1).

### What would change my mind
If FA's median rank stays near 6 with no zero-count HVGs and few tiny noise
variances, the low rank is a property of FA on these data, not of the gene
list, and FA should not be the default positional layer.

## Procedure

1. `t00c_rank.py --genes` — apply the filter, select HVGs, write `genes.txt`.
2. `t00c_rank.py --embed pca|fa|ldvae --dataset v2|v3 [--seed S]` — writes
   `latent_<embed>_<dataset>[_<seed>].npy` and `rank_<embed>_<dataset>[_<seed>].npy`
   under `reports/T00c/`; FA runs also write `fa_noise_<dataset>.npy`.
3. `t00c_rank.py --summarise` — writes `rank_summary.csv` (embed, dataset,
   seed, median_rank, frac_at_ceiling), `fig_rank_dist.png` (one panel per
   embedding, per-cell rank histogram, v2 and v3 overlaid), and prints the
   gated numbers as JSON.
