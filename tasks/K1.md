# K1 — Same chemistry, two runs: pbmc_1k_v3 vs pbmc_10k_v3 (PCA-30, refit yardstick)

status: pre-registered (approved by Tom 2026-10-15; issued 2026-10-15 after K0c/K0d review, PCA-30 kept)
blocked_by: none (K0c, K0d ACCEPT; Tom kept PCA-30)

kind: planned (second step of the K0 → K1 → K2 ladder, PROJECT.md rule 10)

## Purpose

Do basin operators reproduce across **two runs of the same chemistry** on
the same donor's cells, beyond what refitting the drift on one run already
varies? A = 10x `pbmc_1k_v3`, B = a `pbmc_10k_v3` subsample, cell count and
depth matched per cell type. Layer: PCA-30 with tangent-restricted spectra
(rules 1, 3a). Judged with the refit yardstick (rule 12).

- **survives** → operators reproduce across runs; K2 (chemistry) is written.
- **fails** → operators differ between runs of one chemistry beyond fit
  noise; no chemistry test can be read; the ladder stops.
- **inconclusive** → planner brings the numbers to Tom.

## Scope

### In scope
- **Inputs, as staged and verified in T01e (record sha256 of each):**
  `data/pbmc_10k_v3/A_matched.h5ad` (1k v3, 1113 QC cells, depth-matched),
  `data/pbmc_10k_v3/B_matched.h5ad` (10k v3 subsample, 1113 cells,
  count- and depth-matched per type), `reports/T01e/genes.txt` (2000 HVGs,
  sorted before selection). No re-staging, re-matching or new gene list.
  Cell order: file order of each matched file; labels: its `cell_type`.
- **Positional layer:** per dataset, `normalize_total(target_sum=1e4)` then
  `log1p` on the 2000 genes in `genes.txt` order; `PCA(n_components=30,
  svd_solver="full", random_state=20261014)` fit separately on A and on B;
  scores float32 for the drift.
- **Tangent rank and basis:** as K0 (k = 40 other cells,
  `NearestNeighbors(n_neighbors=41)` dropping the first neighbour,
  `np.cov`, `np.linalg.eigh`; rank = count of `w > 0.05 × w.max()`;
  `V` = last 10 columns).
- **Drift fits:** per dataset, for each `s` in `SEEDS = (20261014,
  20261016, 20261017, 20261018, 20261019)`: `EnergyDriftAdapter(dim=30,
  config=EnergyDriftConfig(hidden=96, depth=3, n_epochs=1500, seed=s,
  batch_size=256, loss="esm", lr=5e-4, beta=1.0, esm_laplacian="hutchinson",
  device="cpu")).fit(z)`; `J_s = jacobian_autodiff(z)` (float64 from here);
  `symmetry_check(z, n_cells=100)`. Ten fits.
- **Spectra per seed:** `λ_s = eigvalsh(Vᵀ·½(J_s + J_sᵀ)·V)`;
  `basin_index_s = −max λ_s`; class by `lead_eig` with `tol = 0.1 ×
  median |λ_s|` over that dataset and seed. **Primary operators** are the
  seed-20261014 spectra.
- **Tested types:** ≥ 50 cells in both A and B; `m_t = floor(min(n_A,t,
  n_B,t)/2)`; types in sorted order throughout.
- **Main draws** (`rng = numpy.random.default_rng(20261015)`, this order,
  seed-20261014 spectra): 200 pooled draws (types sorted, `choice` of `m_t`
  A cells; then types sorted, `m_t` B cells); 100 within-fit null draws on
  A (per type `choice` of `2·m_t`, first `m_t` vs rest); 100 on B; 100
  separation draws on A (pairs from `itertools.combinations` of sorted
  types; per pair `choice` of `min(m_a, m_b)` cells of `a`, then of `b`);
  100 on B. All `choice` without replacement over the type's indices in file
  order.
- **Refit draws** (`rng_refit = numpy.random.default_rng(20261020)`): for
  A, then B, 100 draws each, draw `d`: seed pair `(20261014,
  SEEDS[1 + d % 4])`; per type (sorted) `choice` of `2·m_t` cells; the first
  `m_t` are read under fit 20261014, the rest under the other seed's fit;
  spectral W2, basin W1 and class TV per type; mean over types.
- **Statistics:** W2 = `sqrt(ot.wasserstein_1d(x, y, p=2))` on pooled
  restricted eigenvalues; W1 = `ot.wasserstein_1d(..., p=1)` on
  `basin_index`; TV over {"", holder, fork, drift}; mean over types (or
  pairs); median over draws; T01c's ratio convention (0/0 → 1, x/0 → inf).

### Out of scope
- Any layer other than PCA-30; any other `d`, `k`, `r`, floor, epochs,
  seeds; seed averaging; FA or LDVAE.
- New staging, matching, thinning or gene selection; any v2 data; any
  alignment.

### Decision rule
Top to bottom; the first matching line decides. A stop is reported with
`"status": "stopped"` (MANUS.md 8b).
0. **Validity:** `n_cells_a ≠ n_cells_b` → **REVISE** (inputs not the T01e
   matched files). `frac_rank_ge10 < 0.80` → **inconclusive (stop)**.
1. `symmetry_max > 1e-4` → **REVISE**.
2. `n_cell_types_tested < 3` → **inconclusive**.
3. Any of `spectral_sep_a`, `spectral_sep_b`, `basin_sep_a`, `basin_sep_b`
   < 2 → **inconclusive**.
4. `spectral_ratio_refit > 3.0` **or** `basin_ratio_refit > 3.0` →
   **fails**.
5. `spectral_ratio_refit ≤ 1.5` **and** `basin_ratio_refit ≤ 1.5` **and**
   `class_tv_ratio_refit ≤ 1.5` → **survives**.
6. Otherwise → **inconclusive**.

### What would change my mind
`spectral_ratio_refit > 3.0` between two v3 runs of the same donor's cells,
matched for count and depth, means operators carry run-specific structure
three times larger than drift-fit noise; then no chemistry comparison built
on them can be read.

## Procedure

1. `k1_run.py --stage latent` — PCA per dataset (`latent_pca30_a.npy`,
   `latent_pca30_b.npy`), tangent ranks and bases.
2. `k1_run.py --stage fits` — ten drift fits (kept locally); `ops_a.npz`,
   `ops_b.npz` (arrays: `lam_seeds` (5,n,10), `basin_index_seeds` (5,n),
   `cls_seeds` (5,n), `cell_type`, `barcode`), float64.
3. `k1_run.py --stage compare` — `draws.csv` (kind ∈ {pooled, null_a,
   null_b, sep_a, sep_b, refit_a, refit_b}, draw, seed_b, spectral_w2,
   basin_w1, class_tv), gated numbers, `basin_table.csv` (cell_type, n_a,
   n_b, median_bi_a, median_bi_b, class_a, class_b),
   `fig_spectra.png` (per tested type, restricted-eigenvalue density A vs B;
   inset: refit-null and pooled spectral W2 histograms with medians) and
   `fig_basin.png` (per-type median basin_index A vs B, identity line).
4. `k1_run.py --stage report` — `report.json`, checksums, lockfile.

`k1_run.py` must accept `--stage all`.
