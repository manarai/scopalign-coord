## Purpose

Make the rotation an **operator-only estimate**. Earlier attempts failed for
four reasons: too few correspondences (3–5 group means), drift-fit noise
dominating (`r_seed` 0.64 ≫ `r_split` 0.11 in T02c), near-degenerate
spectra, and using curvature (Hessians) only. This task compares five
estimators that address these one at a time, **on problems with a known
answer**, and finds the cell count each needs. It selects one estimator by
a pre-registered rule. No biological or chemistry claim is made here.

- **Test R (known rotation):** two disjoint random subsets of one dataset
  (same frame); the second is rotated by a known orthogonal `Q*`; drift is
  refit on each copy; the estimator must recover `Q*`.
- **Test F (known frame relation):** the two `pbmc_10k_v3` halves with
  separate PCAs; the target is the gene-loading rotation `Q_load(H1→H2)`.

## Scope

### In scope
- **Data (record sha256):** `data/pbmc_10k_v3/pbmc_10k_v3.h5ad`,
  `data/pbmc_10k_v3/k0_halves.csv`, `reports/K0/genes.txt`,
  `reports/K0/latent_pca30_h1.npy`, `reports/K0/latent_pca30_h2.npy`.
  Cells, order and coarse `cell_type` as in K0.
- **Drift fits (all tests):** K0's config (`EnergyDriftConfig(hidden=96,
  depth=3, n_epochs=1500, seed=s, batch_size=256, loss="esm", lr=5e-4,
  beta=1.0, esm_laplacian="hutchinson", device="cpu")`) on the copy's
  30-d latent (float32), for the five seeds `SEEDS = (20261014, 20261016,
  20261017, 20261018, 20261019)`. Per cell and seed: operator
  `M = ½(J + Jᵀ)` (float64, from `jacobian_autodiff`) and drift vector
  `u = drift.velocity(z)` (float64). Seed-averaged: `M̄ = mean_s M`,
  `ū = mean_s u`. `symmetry_check(z, n_cells=100)` per fit.

- **Test R construction.** For each cell count `n ∈ (500, 1000, 2000, 2759)`
  and replicate `r ∈ (0, 1, 2)`:
  `rng = numpy.random.default_rng(20261030 + r)`; `perm = rng.permutation(5518)`
  over H1 cells (K0 order); `S_X = sort(perm[:n])`, `S_Y = sort(perm[n:2n])`
  (disjoint). `X = z_H1[S_X]`; `Q* = scipy.stats.ortho_group.rvs(dim=30,
  random_state=20261031 + r)`; `Y = z_H1[S_Y] · Q*ᵀ`. Fit drifts on X and on
  Y separately. Target: `Q*` (maps X-coordinates to Y-coordinates as column
  vectors).
- **Test F construction.** X = `z_H1` (all 5518), Y = `z_H2` (all 5518),
  separate frames. Re-derive each half's PCA exactly as K0 (subset to
  `genes.txt` genes first, `normalize_total(1e4)`, `log1p`,
  `PCA(30, svd_solver="full", random_state=20261014)`); scores must equal
  K0's latents (`latent_check_max`); `W_1`, `W_2` = `components_`;
  `U, σ, Vᵀ = svd(W_2 W_1ᵀ)`; target `Q_load = U Vᵀ`.

- **Matching groups:** coarse types with ≥ 20 cells in both X and Y
  (sorted). Cells of other types are not matched.
- **Rotation parametrisation and optimiser (all estimators):**
  `Q = Q₀ · matrix_exp(S − Sᵀ)`, torch float64 CPU, `S = 0` at start,
  `LBFGS(lr=1, max_iter=500, tolerance_grad=1e-10, tolerance_change=1e-12,
  line_search_fn="strong_wolfe")`, one `.step` per call.
- **Five estimators** (each run independently on every Test R case and on
  Test F):
  - **E0 — T02 baseline:** type-mean operators from seed 20261014;
    `L(Q) = Σ_t w_t ‖Q M̄_t^X Qᵀ − M̄_t^Y‖² / Σ_t w_t ‖M̄_t^Y‖²`,
    `w_t ∝ min(n_X,t, n_Y,t)`; 20 starts (`I`, then
    `ortho_group.rvs(30, random_state=20261021 + i)`, `i = 1…19`); best loss.
  - **E1 — operator ICP, single seed (fix A):** per-cell operators `M` from
    seed 20261014.
    *Initial match (rotation-invariant):* per group, cost
    `C_ij = ‖λ(M_i^X) − λ(M_j^Y)‖²` with `λ(·)` the ascending eigenvalues;
    `P = ot.emd(uniform, uniform, C)`; each X cell's partner =
    `argmax_j P_ij`.
    *Rotation step:* minimise
    `H(Q) = Σ_pairs ‖Q M_i^X Qᵀ − M_j^Y‖² / Σ_pairs ‖M_j^Y‖²` over the
    current pairs (first iteration: E0's 20 starts, best loss; later
    iterations: warm start from the current `Q`).
    *Re-match:* per group, `C_ij = ‖Q M_i^X Qᵀ − M_j^Y‖²`, `ot.emd`, argmax
    partners. Repeat rotation step and re-match up to 10 times, stopping
    when the partner list is unchanged.
  - **E2 — operator + drift ICP, single seed (A + B):** as E1, with the loss
    `H(Q) + D(Q)`, `D(Q) = Σ_pairs ‖Q u_i^X − u_j^Y‖² / Σ_pairs ‖u_j^Y‖²`,
    and re-match cost `‖Q M_i Qᵀ − M_j‖² / m_M + ‖Q u_i − u_j‖² / m_u`
    (`m_M`, `m_u` = median over all pairs in the group of
    `‖M_j^Y‖²`, `‖u_j^Y‖²`). Initial match as E1. **Initial rotation:**
    orthogonal Procrustes on drift vectors of the initial pairs
    (`U, _, Vᵀ = svd(Σ u_j^Y u_i^Xᵀ)`, `Q₀ = U Vᵀ`), then LBFGS (no random
    starts).
  - **E3 — E2 on seed-averaged fields (A + B + C):** E2 with `M̄`, `ū` in
    place of `M`, `u` everywhere (matching and loss).
  - **E4 — E3 with gap-weighted operators (A + B + C + D):** E3, with each
    per-cell `M̄` replaced, in the Hessian term and in the re-match cost
    (not in the initial invariant match), by
    `M̃ = Σ_{k ∈ top 10 by |λ_k|} g_k λ_k v_k v_kᵀ`, where `(λ_k, v_k)` are
    the eigenpairs of `M̄` and
    `g_k = min(1, gap_k / (0.1 · |λ_k|))`,
    `gap_k = min_{l ≠ k} |λ_k − λ_l|` (over all 30 eigenvalues).
- **Error measures:** `err(Q̂, Q_target) = ‖Q̂ − Q_target‖_F / sqrt(60)`.
  Test R: `err_R` = median over the 3 replicates. Test F: `err_F` (single).
- **Reference for scale:** median `err` of 100 random orthogonal matrices
  (`ortho_group.rvs(30, random_state=20261100 + i)`) against `Q*` of
  replicate 0 → `err_random`.

### Out of scope
- Any estimator, loss weight, iteration count, cell count, seed, OT
  variant, gap rule or threshold other than those above.
- Any v2/v3 or chemistry data; any biological claim; any local map.
- Tuning after seeing errors.

### Decision rule
0. **Validity:** `symmetry_max > 1e-4` or `latent_check_max > 1e-4` →
   **REVISE**.
1. An estimator **works at n** if `err_R_<E>_<n> ≤ 0.10`.
2. An estimator **passes Test F** if `err_F_<E> ≤ 0.25`.
3. **Selection:** the first estimator in the order E0, E1, E2, E3, E4 (simplest
   first) that passes Test F **and** works at n = 1000 →
   `selected_estimator`, `min_n_selected` = smallest n at which it works.
   If none: the first that passes Test F and works at n = 2759 (then O2 must
   use ≥ that many cells per dataset, i.e. not the 1k v2/v3 pair). If none:
   `"none"` — operator-only estimation is not viable with these estimators;
   back to Tom.

### What would change my mind
If no estimator recovers a known rotation to within 0.10 even with 2759
cells per copy, a rotation cannot be estimated from drift-fitted operator
fields at single-cell dataset sizes, and operator alignment must stay a
check rather than an estimator.

## Procedure

1. `o1_run.py --stage testR` — 12 cases (4 n × 3 replicates) × 2 copies × 5
   seeds = 120 drift fits (kept locally); per case `case_<n>_<r>.npz`
   (`S_X`, `S_Y`, `Q_star`, `M_X`, `M_Y` (5, n, 30, 30) float32,
   `u_X`, `u_Y` (5, n, 30), `type_X`, `type_Y`); five estimators;
   `testR.csv` (n, replicate, estimator, err, n_iter, final_loss).
2. `o1_run.py --stage testF` — PCA re-derivation, 10 drift fits, five
   estimators; `testF.npz` (`Q_load`, `Q_hat` per estimator, `M̄`, `ū` for
   both halves, float32); `testF.csv` (estimator, err, n_iter, final_loss).
3. `o1_run.py --stage report` — selection, `fig_recovery.png` (err_R vs n,
   one line per estimator, horizontal lines at 0.10 and `err_random`),
   `report.json`, checksums, lockfile.

`o1_run.py` must accept `--stage all`. The per-case arrays are deliverables
so the planner can recompute any estimator from them without refitting.
(If the arrays exceed 2 GB in total, keep `M_X`/`M_Y` for the
seed-averaged fields only and record that as a deviation.)
