## Purpose

O1k showed that the loss has its minimum at the true rotation, but LBFGS
from 20 random starts never reaches it, even with exact fields. O1l keeps
O1k's loss, landscape, cases and fits and changes only **where the search
starts**:

- **Axis-sign screen (E5s):** each copy's own principal axes (rule 13a:
  positions locate the axes, operators orient them) give a start up to the
  sign of every axis; all 2¹⁰ = 1024 sign patterns are screened by the
  loss, and the 8 best are refined.
- **Basin diagnostic:** starts placed at a known distance from the truth
  show how close a start must be for the search to return to it.

If E5s recovers the rotation from exact fields, the O1-series failures
were a search problem, and the fitted-field numbers (rung B) then say
whether scJDO2's operators carry the rotation (the question O1k could not
answer). If E5s still fails with exact fields, the loss surface is too
rugged near the truth for local search, and the basin radius says by how
much.

## Scope

### In scope
- **Landscape, cases, `Q*_r`, cells, rung A exact fields, rung B fits:**
  exactly O1k (72 cases: rung ∈ (A, B) × γ ∈ (1.0, 1.15, 1.33, 1.6) ×
  n ∈ (1000, 3000, 10000) × r ∈ (0, 1, 2)). Rung B: O1k's cached 360 fits
  from `~/Documents/scopalign-manus-O1k`, read-only, sha256 recorded; no
  new fits. Cells regenerated by O1k's rule; must equal O1k's cached case
  inputs (`inputs_match`).
- **Loss:** O1k's copied E5b `Problem` (`D + H`, `H` subsets from
  `default_rng(20261040 + r)`), unchanged. LBFGS settings as O1k.
- **E5s start set (per case):** `C_X = numpy.cov(x, rowvar=False)`,
  `C_Y` likewise; `eigh`, descending → `U_X`, `U_Y` (10 × 10); record the
  eigenvalues. For every `s ∈ {±1}¹⁰` (in binary order, `s_j = +1` if bit
  `j` of the index `0…1023` is 0): `Q₀(s) = U_Y diag(s) U_Xᵀ`.
  - **Screen:** `L(Q₀(s))` for all 1024 (no optimisation).
  - **Refine:** LBFGS from the 8 lowest (ties broken by index); `Q̂` =
    lowest final `L`. Start workers ≤ 3.
- **Basin diagnostic (n = 3000 cases only, both rungs, all γ and r:
  24 cases):** for `i = 1…5`, `G_i = default_rng(20264400 + i)
  .standard_normal((10, 10))`, `A_i = (G_i − G_iᵀ) / ‖G_i − G_iᵀ‖_F`; for
  each target `t ∈ (0.05, 0.10, 0.20, 0.40)` find `θ` by bisection
  (tolerance 1e-6) so that `‖Q*(expm(θ A_i) − I)‖_F / √20 = t`; start
  `Q₀ = Q* expm(θ A_i)`; LBFGS; record the final `err`. A start
  **returns** if its final `err ≤ 0.10`.
  `basin_radius` (per case) = largest `t` at which ≥ 4 of 5 starts return;
  0 if none.
- **Errors:** O1k's `err`, `err_shape`, `err_pos`; `L(Q̂)`, `L(Q*)`;
  `screen_rank_best` = screen rank of the start that gave `Q̂`.
- **Views (illustration):** as O1k's, with E5s's `Q̂` (rung B, γ = 1.33,
  n = 3000, r = 0).

### Out of scope
- New drift fits, other landscapes, γ, n, seeds; changes to the loss or
  LBFGS settings; random starts beyond O1k's; any start that uses `Q*`
  outside the basin diagnostic; continuation / smoothing schedules;
  cross-copy pairing, labels or gene loadings in the estimate.

### Decision rule
0. Validity → REVISE: `n_cases ≠ 72`, `inputs_match = 0`,
   `l_star_repro_max > 1e-10`, or `negctrl_err_shape_A_s < 0.30` (the
   negative control was recovered).
1. **search_unfixed** if `errA_s_max > 0.10`.
2. Otherwise, with `γ_min` = the smallest γ in (1.15, 1.33, 1.6) whose
   `errB_s_g<γ>_n3000 ≤ 0.10`:
   - **pbmc_range_ok** if `γ_min ∈ (1.15, 1.33)`;
   - **anisotropy_limited** if `γ_min = 1.6`;
   - **fit_limited** if there is none.
- Reading (not the outcome): `basin_radius_A` vs `basin_radius_B` shows
  whether fitting noise shrinks the basin; with search_unfixed,
  `basin_radius_A` says how close any initialiser must start; the n = 10000
  numbers show whether more cells rescue rung B.

### What would change my mind
If the true rotation sits in a basin narrower than 0.10 even with exact
fields, no practical initialiser will find it, and field-equivariance
estimation of a rotation should be dropped regardless of operator quality.
