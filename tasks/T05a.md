## Purpose

T02c's gene-anchored rotation mixed v2 and v3 well (0.90) and kept cell
types apart, and the operators agreed under it. On this easy pair (same
donor, depth- and count-matched), simpler or standard methods may do as
well. This task scores five embeddings of the same cells with the same
three measures — chemistry mixing, cell-type silhouette and **operator
frame agreement** — so they can be compared directly. It is descriptive:
no method "wins" by rule; the pre-registered readings below say what each
comparison means.

## Scope

### In scope
- **Inputs (record sha256 of each):** `data/pbmc_v2_v3/k2_cells.csv`,
  `data/pbmc_v2_v3/pbmc_v2.h5ad`, `data/pbmc_v2_v3/pbmc_v3_thin.h5ad`,
  `reports/T01d/genes.txt`, `reports/K2/latent_pca30_a.npy`,
  `reports/K2/latent_pca30_b.npy`, `reports/T02b/loadings.npz`,
  `reports/T02c/report.json`. A = matched v2, B = matched v3-thin, K2's
  cell order and coarse `cell_type`.
- **Install:** `pip install harmonypy==0.0.10` (record under `deviations`
  as authorised by this task). scvi-tools as already in the venv.
- **Common preprocessing** (methods 1–3): per dataset, subset to the 2000
  genes of `genes.txt`, then `normalize_total(1e4)`, then `log1p` (dense).
- **Five embeddings (each 30-d, all cells of A and B):**
  1. `joint` — stack A then B; `PCA(30, svd_solver="full",
     random_state=20261014)` on the stack (uncorrected reference; = T02c view 1).
  2. `centre` — subtract each dataset's own gene means from its log matrix,
     stack, then `PCA(30, svd_solver="full", random_state=20261014)`.
  3. `harmony` — `harmonypy.run_harmony(joint_scores, meta, "dataset",
     random_state=20261014, max_iter_harmony=20)` with `meta` a DataFrame
     with column `dataset` ∈ {A, B}; embedding = `Z_corr.T`.
  4. `scvi` — raw counts of the 2000 genes, A then B,
     `scvi.settings.seed = 20261014`;
     `scvi.model.SCVI.setup_anndata(adata, batch_key="dataset")`;
     `SCVI(adata, n_latent=30)` (other settings default);
     `train(max_epochs=400, accelerator="cpu", devices=1)`;
     embedding = `get_latent_representation()`.
  5. `ours` — `[z_A · Q_loadᵀ ; z_B]` from K2's latents and
     `Q_load = U Vᵀ` of `W_B W_Aᵀ` (T02b loadings), as T02c view 3.
- **Scores per embedding** (exactly T02c's definitions, on the 30-d
  embedding): `mix` (30 nearest other cells, fraction from the other
  dataset, ÷ 0.5) and `sil` (silhouette on K2's tested types).
- **Operator frame agreement per embedding** (same procedure for all five,
  in the shared 30-d space, **full 30 dimensions**):
  - per dataset, fit the drift on that dataset's cells **in this embedding**
    (float32), K2's config, seeds 20261014, 20261016, 20261017, 20261018,
    20261019; `M_c = ½(J_c + J_cᵀ)` float64; `symmetry_check`;
  - clusters: coarse types with ≥ 100 cells in both (as T02c); weights as
    T02c; centroid operators via
    `scjdo2.compare.centroid_operator(z_k, M_k, n_cells_centroid=30)`;
  - `frame_resid` = T02c's residual between A's and B's seed-20261014
    centroid operators (full 30×30, no rotation: the space is shared);
  - `frame_null` = T02c's null procedure (`default_rng(20261022)`, A then B,
    seed pairs (20261014, 20261016…19), half-splits), full 30×30; median;
  - `frame_ratio = frame_resid / frame_null`; `frame_outcome` by T02c's
    thresholds (≤ 1.5 agreement, > 3.0 no agreement, else inconclusive).
  The five embeddings are processed in the order listed; each uses its own
  fresh `default_rng(20261022)`.

### Out of scope
- Any other method, setting, `d`, seed, epoch count or Harmony parameter;
  any re-tuning after seeing a score.
- Top-10 restriction (T02c used it; here all embeddings use the full 30-d
  space so that unordered latents like scVI's are treated the same).
- Other datasets; using any method's output to change earlier results.

## Pre-registration

### Gated numbers
For each method `m` ∈ {joint, centre, harmony, scvi, ours}:
| name | definition | computed by |
|------|-----------|-------------|
| `mix_joint` | mixing, joint | `python reports/T05a/scripts/t05a_run.py --stage scores` |
| `mix_centre` | mixing, centre | same |
| `mix_harmony` | mixing, harmony | same |
| `mix_scvi` | mixing, scvi | same |
| `mix_ours` | mixing, ours | same |
| `sil_joint` | silhouette, joint | same |
| `sil_centre` | silhouette, centre | same |
| `sil_harmony` | silhouette, harmony | same |
| `sil_scvi` | silhouette, scvi | same |
| `sil_ours` | silhouette, ours | same |
| `frame_ratio_joint` | frame ratio, joint | `--stage operators` |
| `frame_ratio_centre` | frame ratio, centre | same |
| `frame_ratio_harmony` | frame ratio, harmony | same |
| `frame_ratio_scvi` | frame ratio, scvi | same |
| `frame_ratio_ours` | frame ratio, ours | same |
| `frame_outcome_joint` | T02c thresholds on `frame_ratio_joint` | same |
| `frame_outcome_centre` | same, centre | same |
| `frame_outcome_harmony` | same, harmony | same |
| `frame_outcome_scvi` | same, scvi | same |
| `frame_outcome_ours` | same, ours | same |
| `n_clusters` | coarse types with ≥ 100 cells in both | same |
| `symmetry_max` | max `median_asym` over all 50 fits | same |
| `ours_repro_max_abs` | max \|`mix_ours` − T02c `mix_sep_load`\|, \|`sil_ours` − T02c `sil_sep_load`\| | `--stage scores` |

### Decision rule
Validity only: `ours_repro_max_abs > 1e-6` or `symmetry_max > 1e-4` →
**REVISE**; `n_clusters < 3` → **stopped**. Otherwise the task is
complete; there is no single outcome.

**Pre-registered readings (descriptive):**
- *Mixing:* a method "mixes" if `mix ≥ 0.80`.
- *Biology:* a method "keeps types" if `sil ≥ 0.9 × sil_joint`.
- *Operators:* per method, `frame_outcome` as above.
- *Ours vs the rest:* "ours is competitive" if `mix_ours ≥ max(other
  mix) − 0.05` **and** `sil_ours ≥ max(other sil) − 0.02`; "ours adds
  operator information" if `frame_outcome_ours` is agreement while at least
  one method that "mixes" and "keeps types" does not reach agreement.
- If every method that mixes also reaches operator agreement, the pair is
  too easy to separate the methods, and the comparison moves to T03-scale
  data.

### What would change my mind
If a standard method (Harmony or scVI) mixes as well, keeps types as well
and also reaches operator agreement, the gene-anchored rotation offers
nothing extra on this pair.

## Procedure

1. `t05a_run.py --stage embed` — five embeddings → `embeddings.npz`
   (`joint`, `centre`, `harmony`, `scvi`, `ours` (n, 30), `dataset`,
   `cell_type`).
2. `t05a_run.py --stage scores` — `mix`, `sil`, reproduction check →
   `scores.csv` (method, mix, sil).
3. `t05a_run.py --stage operators` — 50 drift fits (kept locally),
   centroid operators → `centroid_ops.npz` (per method: `C_a`, `C_b`
   (seeds, clusters, 30, 30), `null_h1`, `null_h2` (8, clusters, 30, 30));
   `frames.csv` (method, frame_resid, frame_null, frame_ratio,
   frame_outcome).
4. `t05a_run.py --stage views` — `fig_umap.png` (5 rows = methods × 2
   columns = coloured by dataset / cell type; UMAP as T02c with
   `random_state=20261014`; titles with mix, sil, frame_ratio).
5. `t05a_run.py --stage report` — `report.json`, checksums, lockfile.

`t05a_run.py` must accept `--stage all`.
