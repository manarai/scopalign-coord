# T00b — Positional layer: does FA avoid the tangent-rank ceiling?

status: pre-registered
blocked_by: T00
seed: 20261014
planner_commit: fa2f340

## Purpose

scJDO2's spec records that PCA latents saturate the local tangent rank at
`d`, which makes basin calls uninformative. scOpAlign needs a linear
decoder, so PCA, FA and LDVAE are the candidates. This task measures the
tangent-rank distribution under each at the same `d` on the T01 data, and
fixes the positional layer for every downstream task. No operators are
estimated here.

## Scope

### In scope
- Data: `data/pbmc_v2_v3/pbmc_v2.h5ad` and `pbmc_v3.h5ad`, cells with
  `obs['qc_pass'] == True`.
- Genes: intersection of both files, then top 2000 HVGs on the
  concatenated matrix (`flavor='seurat_v3'`, `batch_key=None`). Same gene
  list for both datasets.
- Normalisation for PCA and FA: `normalize_total(1e4)` then `log1p`.
  LDVAE uses raw counts with `batch_key=None`.
- `d = 30` for all three. Each embedding fit **separately** per dataset.
- PCA: `sklearn.decomposition.PCA(30, random_state=seed)`.
- FA: `sklearn.decomposition.FactorAnalysis(30, random_state=seed, max_iter=2000)`.
- LDVAE: `scvi.model.LinearSCVI(n_latent=30)`, `max_epochs=250`, seeds
  `{20261014, 20261015, 20261016}` (set `scvi.settings.seed = S` before
  each fit); train with `accelerator="cpu", devices=1`; report the median
  over seeds.
- Tangent rank per cell: eigenvalues of the local covariance of the `k=40`
  nearest neighbours in latent; rank = number of eigenvalues above
  `0.05 × λ_max`. (This is the kNN-Σ magnitude-floor rule used in
  `scjdo2.opspace.classify_basin_latent`; use `tangent_floor_frac=0.05`.)

### Out of scope
- Any drift fit or Hessian.
- Any alignment.
- Other values of `d`, `k`, or the floor fraction.
- scVI with a nonlinear decoder.

## Pre-registration

### Gated numbers
| name | definition | computed by |
|------|-----------|-------------|
| `rank_pca_v2` | median tangent rank, PCA, v2 | `python reports/T00b/scripts/t00b_rank.py` |
| `rank_pca_v3` | same, v3 | same |
| `rank_fa_v2` | median tangent rank, FA, v2 | same |
| `rank_fa_v3` | same, v3 | same |
| `rank_ldvae_v2` | median over seeds of median tangent rank, LDVAE, v2 | same |
| `rank_ldvae_v3` | same, v3 | same |
| `frac_fa_at_ceiling` | fraction of cells (both datasets pooled) with FA rank ≥ 28 | same |

### Decision rule
- `frac_fa_at_ceiling ≤ 0.20` → **FA is the positional layer** for T01
  onward.
- `frac_fa_at_ceiling > 0.20` and `rank_ldvae_*` median is at least 5 below
  `rank_fa_*` in both datasets → **LDVAE** is the positional layer; seed
  fixed at 20261014.
- Otherwise → inconclusive; planner writes T00c with a density-aware rank
  estimator before T01.

## Procedure

1. `t00b_rank.py --embed pca|fa|ldvae --dataset v2|v3 [--seed S]` writes
   `reports/T00b/latent_<embed>_<dataset>[_<seed>].npy` (n × 30) and
   `rank_<embed>_<dataset>[_<seed>].npy`.
2. `t00b_rank.py --summarise` writes `rank_summary.csv` (embed, dataset,
   seed, median_rank, frac_at_ceiling) and `fig_rank_dist.png` (one panel
   per embedding, histogram of per-cell rank, v2 and v3 overlaid).
