runs, and stage the T01 data locally: raw counts, QC flag and cell-type

    label mapping is needed.

- scJDO2 and `EnergyDriftAdapter` import, both `.h5ad` files exist with `X`,
  `obs['qc_pass']` and `obs['cell_type']`, and both `n_cells_*_qc ≥ 400`
  (T01's split-half null draws 200 cells per half-pair) → ACCEPT; planner
  copies the failing test IDs into `KNOWN_FAILURES`.
- Otherwise → REVISE.

## Procedure

1. Install Python 3.11, create venv, install as above,
   `pip freeze > reports/T00/requirements.lock`.
2. Run the import check and pytest; save pytest output to
   `reports/T00/pytest_scjdo2.txt`; extract failing IDs.
3. `python reports/T00/scripts/t00_stage.py --stage download` — downloads,
   writes `data_checksums.txt`.
4. `python reports/T00/scripts/t00_stage.py --stage build` — writes both
   `.h5ad` files and `reports/T00/cell_type_counts.csv`
   (columns: cell_type, n_v2_qc, n_v3_qc).
5. `python reports/T00/scripts/t00_stage.py --stage summary` — prints the
   gated numbers as JSON; assemble `report.json`.

`t00_stage.py` must also accept `--stage all`.
