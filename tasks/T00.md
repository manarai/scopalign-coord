## Purpose

Produce a reproducible `.venv`, confirm scJDO2 and scJDO v1 import and their
test suites run, and stage the T01 dataset locally. Establish the
`KNOWN_FAILURES` baseline. No scientific numbers.

## Scope

### In scope
- Python 3.11 venv at `~/Documents/scopalign-manus/.venv`.
- Install: `scanpy`, `scikit-learn`, `scipy`, `POT`, `jsonschema`,
  `matplotlib`, `pandas`, `anndata`, `scJDO2` (git+https://github.com/manarai/scJDO2 @ main, record the sha),
  `scJDO` v1 (git+https://github.com/manarai/scJDO @ the preprint tag, record the tag).
- Run `pytest` in the installed scJDO2 and scJDO packages; list every
  failing test ID.
- Download the 10x PBMC v2/v3 same-donor pair into `data/pbmc_v2_v3/`
  as `pbmc_v2.h5ad`, `pbmc_v3.h5ad`, each with `obs['qc_pass']` (bool,
  standard scanpy QC: min_genes=200, max pct_mt=20) and `obs['cell_type']`
  (harmonised labels from the 10x-provided annotation; if labels differ
  between files, map to the coarser set and record the mapping in
  `label_map.csv`).

### Out of scope
- Any operator estimation.
- Any other dataset.

## Procedure

1. Create venv, install packages, `pip freeze > reports/T00/requirements.lock`.
2. Run pytest for both packages, save `reports/T00/pytest_scjdo2.txt`,
   `reports/T00/pytest_scjdo.txt`, extract failing IDs.
3. `scripts/t00_stage.py` downloads and prepares the two `.h5ad` files and
   writes `label_map.csv` if needed.
4. Assemble `report.json`.
