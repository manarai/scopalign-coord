    `normalize_total(target_sum=1e4)` + `log1p` over all genes, using all
    cells. Store `predicted_labels`. The same model labels both files, so no
    label mapping is needed.

### Decision rule
- scJDO2 imports, both `.h5ad` files exist with `X`, `layers['spliced']`,
  `layers['unspliced']`, `obs['qc_pass']`, `obs['cell_type']`, and
  `0.05 ≤ frac_unspliced ≤ 0.50` in both → ACCEPT; planner copies the failing
  test IDs into `KNOWN_FAILURES`.
- Otherwise → REVISE.

### What would change my mind
Not applicable; this is infrastructure. An unspliced fraction outside
0.05–0.50 means the velocyto step is broken, not a finding.

## Procedure

1. Create venv, install as above, `pip freeze > reports/T00/requirements.lock`.
2. Run pytest; save output to `reports/T00/pytest_scjdo2.txt`; extract failing IDs.
3. `python reports/T00/scripts/t00_stage.py --stage download` — downloads,
   writes `data_checksums.txt`.
4. `python reports/T00/scripts/t00_stage.py --stage velocyto` — runs velocyto
   for both chemistries.
5. `python reports/T00/scripts/t00_stage.py --stage build` — writes both
   `.h5ad` files and `reports/T00/cell_type_counts.csv`
   (columns: cell_type, n_v2_qc, n_v3_qc).
6. `python reports/T00/scripts/t00_stage.py --stage summary` — prints the
   gated numbers as JSON; assemble `report.json`.

`t00_stage.py` must also accept `--stage all`.
