    header-only file (`label_v2,label_v3,label`).

## Procedure

1. Install Python 3.11, create venv, install, run the v1 install script,
   `pip freeze > reports/T00/requirements.lock`.
2. Run both pytest commands → `reports/T00/pytest_scjdo2.txt`,
   `reports/T00/pytest_scjdo.txt`; extract failing IDs.
3. `reports/T00/scripts/t00_stage.py` downloads, writes
   `data_checksums.txt`, prepares both files, writes `label_map.csv`.
   `--count` prints the two raw cell counts as JSON.
4. Assemble `report.json`.
