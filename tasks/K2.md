## Purpose

Do basin operators agree across **two chemistries** (10x v2 vs v3) on the
same donor's cells, beyond what refitting the drift on one dataset already
varies? Same design and decision rule as K1 (PCA-30, tangent-restricted
spectra, refit yardstick; PROJECT.md rules 1, 3a, 12), on the v2/v3 pair,
matched for depth (T01d's thinning) and for cell count per type.

K1 was inconclusive (spectral refit ratio 1.529 vs the 1.5 line), so a
two-run baseline is not established. K2 therefore also reports its ratios
**relative to K1's** (secondary), to show whether chemistry adds anything
beyond run-to-run variation at this sample size.

- **survives** → operators agree across chemistries at matched count and
  depth; planner brings a T02 proposal to Tom (T02 stays Tom's decision,
  because K1 did not pass).
- **fails** → operators differ across chemistries beyond fit noise; the
  axiom as written fails for this pair at this power; project pauses.
- **inconclusive** → planner brings the numbers to Tom.

## Scope

### In scope
- **Inputs (record sha256 of each):** `data/pbmc_v2_v3/pbmc_v2.h5ad` (QC
  cells: `obs['qc_pass'] == True`, 992), `data/pbmc_v2_v3/pbmc_v3_thin.h5ad`
  (v3 thinned to v2's per-type depth by T01d; all 1113 cells are QC cells),
  `reports/T01d/genes.txt` (2000 HVGs, sorted before selection). No
  re-thinning, re-QC, relabelling or new gene list. Labels: each file's
  `cell_type`. Cell order: file order.
- **Count matching:** `rng_match = numpy.random.default_rng(20261014)`. For
  each cell type present in both datasets, in sorted order:
  `n_t = min(n_v2,t, n_v3,t)`; `rng_match.choice` of `n_t` v2 cells of that
  type (over their indices in file order, without replacement), then
  `rng_match.choice` of `n_t` v3-thin cells of that type. Types present in
  only one dataset are dropped. Each matched dataset is then put back in
  file order. Write `data/pbmc_v2_v3/k2_cells.csv` (barcode, dataset).
  "A" = matched v2, "B" = matched v3-thin.
- **Positional layer (explicit order):** per dataset, (1) subset the
  matched cells to the 2000 genes of `reports/T01d/genes.txt`, in that
  order; (2) `sc.pp.normalize_total(target_sum=1e4)` on that 2000-gene
  matrix; (3) `sc.pp.log1p`; (4) `PCA(n_components=30, svd_solver="full",
  random_state=20261014)`, fit separately on A and on B; scores float32 for
  the drift.
- **Everything else exactly as `tasks/K1.md`:** tangent rank and basis
  (k = 40 other cells, floor 0.05, last 10 eigenvectors); drift fits with
  `SEEDS = (20261014, 20261016, 20261017, 20261018, 20261019)` per dataset
  (ten fits; float64 after the Jacobian); per-seed restricted spectra,
  `basin_index`, classes and `tol`; seed-20261014 spectra as primary
  operators; tested types (≥ 50 cells in both); `m_t`; main draws on
  `default_rng(20261015)` and refit draws on `default_rng(20261020)` in
  K1's order; all W2/W1/TV definitions, means, medians and the ratio
  convention.
- **K1 reference values** (from `reports/K1/report.json`, merged at
  a4ed661): `spectral_ratio_refit` 1.5294658061679813,
  `basin_ratio_refit` 0.8718013824357383,
  `class_tv_ratio_refit` 1.0941906957865921.

### Decision rule
K1's rule, unchanged. Top to bottom; the first matching line decides. A
stop is reported with `"status": "stopped"` (MANUS.md 8b).
0. **Validity:** `count_match_max_abs > 0` or `depth_match_max_rel > 0.05`
   → **REVISE**. `frac_rank_ge10 < 0.80` → **inconclusive (stop)**.
1. `symmetry_max > 1e-4` → **REVISE**.
2. `n_cell_types_tested < 3` → **inconclusive**.
3. Any of `spectral_sep_a`, `spectral_sep_b`, `basin_sep_a`, `basin_sep_b`
   < 2 → **inconclusive**.
4. `spectral_ratio_refit > 3.0` **or** `basin_ratio_refit > 3.0` →
   **fails**.
5. `spectral_ratio_refit ≤ 1.5` **and** `basin_ratio_refit ≤ 1.5` **and**
   `class_tv_ratio_refit ≤ 1.5` → **survives**.
6. Otherwise → **inconclusive**.

**Secondary reading (not part of the outcome):** if `spectral_vs_k1` or
`basin_vs_k1` > 2, chemistry adds more than twice K1's run-to-run
difference; if both are ≤ 1.25, the v2/v3 difference is no larger than
K1's run-to-run difference at this sample size.

### What would change my mind
`spectral_ratio_refit > 3.0` between v2 and v3 at matched count and depth,
with operators that separate cell types, means chemistry reshapes the wells
by more than three times the drift-fit noise: the axiom as written fails
for a chemistry change.

## Procedure

1. `k2_run.py --stage match` — count matching; `k2_cells.csv`;
   `reports/K2/match_table.csv` (cell_type, n_v2_qc, n_v3thin, n_matched,
   median_depth_a, median_depth_b).
2. `k2_run.py --stage latent` — `latent_pca30_a.npy`, `latent_pca30_b.npy`,
   tangent ranks and bases.
3. `k2_run.py --stage fits` — ten drift fits (kept locally); `ops_a.npz`,
   `ops_b.npz` (as K1), float64.
4. `k2_run.py --stage compare` — `draws.csv` (as K1), gated numbers,
   `basin_table.csv`, `fig_spectra.png`, `fig_basin.png` (as K1).
5. `k2_run.py --stage report` — `report.json`, checksums, lockfile.

`k2_run.py` must accept `--stage all`.
