## Purpose

**Exploratory. Reported beside T01c, never in place of it. It cannot change
T01c's outcome (INCONCLUSIVE, rule 3) and does not count toward any
pre-registered axiom test.**

In T01c, v2's eigenvalues are about 6.3× larger in magnitude than v3's
(median |λ| 30.3 vs 4.8), and `spectral_ratio` is 53.7. An orthogonal
alignment cannot change eigenvalues, so if chemistry rescales the whole
spectrum, the axiom as written fails even when the shape of the wells
agrees. This task divides each dataset's eigenvalues by one number, its
median |λ|, and recomputes the between-chemistry statistics on exactly the
same draws as T01c. The answer feeds a design decision for Tom: keep the
axiom as written, or restate it as "wells agree up to one per-dataset
scale".

What scaling can and cannot change, by construction:
- Basin classes are already scale-invariant (`lead_eig` compares the leading
  eigenvalue with `0.1 × median |λ|` of the same dataset), so class
  statistics equal T01c's exactly. Used here as a validity check only.
- Within-dataset separations (`*_sep_*`) are ratios of distances inside one
  dataset, so the scale cancels; they equal T01c's exactly. Validity check
  only. In particular T01c's rule-3 guard (`basin_sep_v2` = 1.22) is
  unchanged.
- Only the between-chemistry ratios (`spectral_ratio`, `basin_ratio`) can
  move. They are the point of this task.

## Scope

### In scope
- Inputs: `reports/T01c/ops_v2.npz` and `ops_v3.npz` as committed (arrays
  `eig` (n, 30) real, `cell_type` str; one row per QC cell, file order).
  Record both files' sha256. **No drift fit, no refit, no new Jacobians.**
- Scale per dataset: `s_D = median |λ|` over all eigenvalues of all cells
  in `eig` for dataset D. Scaled eigenvalues `λ' = λ / s_D`.
- Per cell from scaled eigenvalues: `lead = max(λ')`;
  `basin_index' = −lead`; class = `fork` if `lead > 0.1`, `holder` if
  `lead < −0.1`, else `drift` (this is `classify_basin_latent(rule="lead_eig")`
  with `tol = 0.1 × median |λ'| = 0.1`; computed directly from `eig`).
- Tested types, `m_t`, W2/W1/TV definitions, ratio convention, and the
  draw procedure: exactly as in `tasks/T01c.md`, with one
  `numpy.random.default_rng(20261014)` consumed in the same order (200
  pooled; 100 null v2; 100 null v3; 100 separation v2; 100 separation v3),
  so every draw samples the same cells as T01c.

### Out of scope
- Any drift fit, Jacobian recomputation, or other dataset.
- Any normalisation other than the single `s_D` per dataset (no per-type,
  per-cell, or rank-based scaling).
- Changing any threshold, `m_t`, number of draws, or the generator order.
- Any statement about the axiom's outcome; T01c's outcome stands.

### Reading rule (exploratory — informs a design proposal, not an outcome)
Applied top to bottom.
1. `|class_tv_ratio_s − 6.508188| > 1e-5` or `max_sep_change ≥ 1e-6` →
   **REVISE** (implementation does not reproduce T01c's draws).
2. `spectral_ratio_s ≤ 1.5` **and** `basin_ratio_s ≤ 1.5` → **"global
   scale"**: the between-chemistry difference in spectra and basin_index
   is explained by one number per dataset. The planner brings Tom a
   proposal to restate the axiom with a per-dataset scale, to be tested in
   a new pre-registered task on a second replicate pair.
3. `spectral_ratio_s > 3.0` **or** `basin_ratio_s > 3.0` → **"shape
   differs"**: a global scale does not explain the difference; scale is not
   the fix.
4. Otherwise → **"partly scale"**: reported as is; no design proposal from
   this task alone.
